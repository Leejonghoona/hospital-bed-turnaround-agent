# 환자 분류 코드 체계 조사 (병상 배정과 담당 검토 판단용)

조사일 2026-11-08. 합성 데이터 데모의 설계를 보정하려는 조사다. 실제 환자 데이터는 쓰지 않았다.
표기: [1차] 정부 지침·법령·표준 명세 원문을 직접 확인함. [2차] 논문·기사·병원 안내·사본. [확인 못 함] 근거를 찾지 못함.

## 1. 요약 (지금 설계 LP-01에서 빠진 것과 고칠 것)

1. **비말주의가 없다.** `IsolationType`에는 공기와 접촉만 있다. 질병관리청 지침은 비말주의 환자를 "가능한 한 1인실"에 두고, 1인실이 모자라면 같은 병원체 환자끼리 코호트(병상 간격 1m 이상)를 허용한다[1차].
2. **"접촉 격리 → 음압실 또는 1인실"은 지침보다 엄격하고 방향도 어긋난다.** 접촉주의에는 음압이 필요 없다. 지침은 1인실을 우선하고, 없으면 같은 균끼리 코호트를 허용한다. 음압실은 공기주의 몫으로 아껴야 한다[1차].
3. **격리는 값 하나가 아니라 집합이다.** 수두는 공기+접촉, 배액이 있는 폐외결핵도 공기+접촉이다[1차]. 코호트를 판단하려면 **병원체(코호트 키)**와 **상태(확진, 의심, 선제)**가 함께 있어야 한다.
4. **선제 격리 해제 규칙이 따로 있다.** 과거 입원 때 CRE, VRE, VRSA가 분리된 환자는 선제 격리 후 선별검사를 한다. 1일 이상 간격으로 2회 연속 음성이면 해제한다. 다제내성균 격리실 우선순위와 해제는 **감염관리실무자**가 정한다[1차]. "주치의 오더 값만"이라는 입력 주체를 "격리 오더(주치의 또는 감염관리실)"로 넓혀야 한다.
5. **코호트에는 금지 동실 조건이 있다.** 면역저하 환자나 개방창상 환자와 같은 병실에 두면 안 된다[1차]. 환자 속성이 필요하다.
6. **턴어라운드에 직접 영향을 준다.** 공기주의·비말주의 환자가 퇴실한 병실은 에어로졸이 없어질 때까지 기다린 뒤 청소한다. 접촉주의는 퇴실 후 청소가 끝날 때까지 유지한다. C. difficile 오염 병실은 아포 대응 소독이 필요하다[1차]. 종말소독의 하위 유형과 대기 시간을 모델에 넣어야 한다.
7. **법정 감염병 급수는 전파경로 주의와 다른 축이다.** 1급은 음압격리급이고 감염병관리기관 입원 대상이다[1차]. 데모에서는 배정 대상이 아니라 담당 검토(전원) 사유로 둔다.
8. **1인실 병실료 차액은 사유에 따라 갈린다.** 상급종합병원 1인실은 비급여 전액이다. 다만 격리치료 대상 환자가 1인실에 입원하면 비급여에서 빠진다[1차, 사본]. `single_room_reason`(격리, 희망)을 나눠야 차액 동의 검토를 올바르게 건다.
9. **간호·간병통합서비스에는 환자(불가 시 보호자) 동의서가 필요하다.** 2024년 12월부터 중증·인지장애 환자를 우선 제공 대상으로 한다[1차]. 낙상, 섬망, KTAS, KPCS는 국가 단위의 병실 배정 규칙이 아니다. 점수나 검토 사유로 둔다.
10. **표준 코드:** HL7 v2 PV2-41 Precaution Code(표 0433)에는 격리 코드가 없다. FHIR R4에도 격리 전용 요소가 없다. KR Core 1.0.2에는 격리 코드체계나 Flag 프로파일이 없다. 그래서 Flag와 SNOMED CT로 표현하는 것을 제안한다(코드 번호 확인함).

**부여·해제 주체와 시점:** 지침은 "누가 오더를 내는가"를 정하지 않는다. 다제내성균 부록은 격리실 우선순위와 해제 시기를 **감염관리실무자**가 정한다고 적었다(부록1 A 5.2.1, 5.3.1)[1차]. 부여 시점은 의심 시점(외래 선별 체계, 5.5.2.7)이고, 다제내성균은 "어느 부위에서든 균이 분리되는 경우"다(A 5.1.1). 병원별 HIS의 오더 주체(주치의 또는 감염관리실 자동 플래그)는 [확인 못 함]이다.

**CDC 2007:** 질병관리청 지침의 부록1 표가 CDC/HICPAC 2007 Appendix A를 출처로 밝혀 둔다. cdc.gov 원문은 이 환경에서 접근이 차단돼(403, 아카이브 차단) 직접 열람하지 못했다. 그래서 위 표는 국내 번역판을 1차 근거로 삼았다.

### 2.7 소아

- 의료법 시행규칙 별표4(시설규격)에는 소아 병실 조항이 없다[1차, 원문 검색]. 연령 기준과 성인 혼합 허용 여부는 **병원 내규**다.
- 서울대병원 어린이병원 소아응급실은 2024.9.23부터 만 18세 미만을 대상으로 한다[2차, 병원 공지]. 병동 입원 연령 기준과 보호자 상주 인원을 공개한 1차 자료는 [확인 못 함]이다.
- 신생아 격리 시 침상 간격은 충분히 넓게(5.3.2.5)[1차]. 홍역, 수두, 백일해처럼 소아에 흔한 비말·공기 감염이 겹친다.

## 3. 병상 배정 규칙으로 옮길 때의 제안

### 3.1 온톨로지 개념 계층 (rdfs:subClassOf)

```
환자 측 (요구 개념)
TransmissionPrecaution
 ├ StandardPrecaution
 ├ ContactPrecaution ─ requires → SingleOrCohortRoom
 │   ├ MDROContact (organism: CRE|VRE|VRSA|MRSA|MRPA|MRAB)
 │   │   └ CREContact ─ requires → SingleRoom (1인실 최우선; 코호트는 담당 검토)
 │   └ CDiffContact ─ cleaningRequires → SporicidalTerminal
 ├ DropletPrecaution ─ requires → SingleOrCohortRoom
 └ AirbornePrecaution ─ requires → NegativePressureRoom
     ├ MeaslesAirborne, VaricellaAirborne ─ cohortAllowed(같은 바이러스)
     └ ActivePulmonaryTBAirborne ─ cohortAllowed false
PrecautionStatus: Confirmed | Suspected | Preemptive(선별 대기)
ProtectiveNeed: Immunocompromised, OpenWound  (코호트 동실 금지 대상)

병실 측 (공급 개념)
Room
 ├ MultiBedRoom (≤4)
 │   └ CohortRoom (cohortKey = 병원체 코드)
 └ SingleRoom
     └ NegativePressureRoom (AIIR: 전실, ACH≥6, 차압≥2.5Pa)
```

- SingleOrCohortRoom은 `SingleRoom ⊔ (CohortRoom ∧ cohortKey = 환자 병원체)`로 정의한다. NegativePressureRoom은 SingleRoom의 하위라서 자동으로 충족되지만, 공기주의가 아니면 **음압실 사용 감점**(아래 3.2)으로 아낀다.
- 복합 격리(수두 A+C)는 개념 두 개를 동시에 갖게 하고, SHACL이 각각을 검사한다.

### 3.3 합성 데이터 생성기에 추가할 필드 (`sim/models.py` 기준)
