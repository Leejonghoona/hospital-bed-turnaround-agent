# 병실관리AI 데모 가이드 (2026-11-10)

모든 데이터는 합성(가상)이고, 수치는 합성 데이터 기준 추정입니다. 병원 발표 수치와 비교하지 않습니다.

## 1. 한 줄 요약
퇴원 확정부터 다음 환자 입실까지를 사건으로 추적합니다. 평범한 배정은 에이전트가 확정하고 병동·원무에 알립니다. 사람은 책임질 순간에만 개입합니다. 환자 연락, 안전 예외, 시스템이 "확인 필요"로 올린 판단이 그런 순간입니다. 새 병원은 자기 내보내기 표를 올리고 질문에 답하면 그 병원에 맞게 설정됩니다.

## 2. 실행
```bash
pip install -e .
```
```bash
streamlit run src/turnaround/ui/app.py
```
- 왼쪽 "보기"에서 **시연 대본**을 고르고 장면을 선택한 뒤 **다음 ▶**을 누릅니다. 장면마다 3~5단계입니다.
- **역할 화면**에서는 시드와 시각을 골라 원무·병동·감염관리실·관리자·청소 협력업체 화면을 직접 눌러 볼 수 있습니다(승인, 되돌리기, 준비 완료, 이의, 확인).
- API 키가 없어도 돕니다(결정적 가짜 LLM). 외부 모델은 합성 데이터 확인 환경 변수가 있을 때만 붙고, 병원 데이터는 외부로 보내지 않습니다(`external_llm: deny` 집행).

| | 관리자 18:00 | 오늘 한눈에, 구간 지표, 안전 4종 위반 0 | 안전은 실행된 기록으로 검사한다 |

## 6. 정직하게 말할 한계
- 합성 데이터와 사람 응답 모형(연락 20분, 병동 준비 30분 등)은 설계 가정입니다.
- 상황별 금지 규칙은 정답 세트를 보고 정리했습니다. 같은 세트로 잰 "실행 금지 0"은 낙관적입니다.
- 현실 가동률에서 12시 이전 퇴실 효과는 거의 없습니다(+2건/138). 효과는 입실 대기(−13%)와 청소 지연 감소에서 나타납니다.
- 답 재사용 사전은 같은 열 이름이 다시 나올 때만 질문을 줄입니다.
- 사람이 작업을 끝내는 흉내가 재생에 없어 마감 초과 올림 수는 실제 부담 지표가 아닙니다.
