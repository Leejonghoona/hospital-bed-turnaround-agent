# 구독 경유 Claude 측정 가이드 (윈도우 노트북)

API 키 없이 구독(Pro·Max) 계정으로 Claude 모델 세 개(Haiku, Sonnet, Opus)를 잰다. 잰 결과는 자동으로 저장소에 올라간다.
지금 재는 것: 프롬프트 인젝션 방어, 질의응답, 병상 선택. 메모 추출은 현직자 설문 답으로 라벨을 확정한 뒤 추가한다.

## 처음 한 번만 (10~15분)
1. Python 3.11 설치(설치 화면에서 "Add python.exe to PATH" 체크), Git for Windows 설치.
2. Claude Code 설치 후 PowerShell에서 `claude` 실행 → 브라우저에서 구독 계정 로그인 → `/exit`.
3. 저장소 받기(바탕화면 등 원하는 곳의 PowerShell에서):
   `git clone -b claude/gallant-keller-0lrkwf https://github.com/leejonghoona/hospital-bed-turnaround-agent.git`
   처음 푸시할 때 GitHub 로그인 창이 한 번 뜬다.

## 그다음부터: 둘 중 하나만
- **방법 A (더블클릭)**: 저장소 폴더의 `scripts\run_claudesub.bat`을 더블클릭한다. 최신 코드 받기 → 측정 → 결과 저장 → 커밋·푸시까지 자동. 창이 "끝."을 보여 주면 닫는다.
- **방법 B (요청)**: 저장소 폴더에서 `claude`를 실행하고 `/claude-measure`를 입력한다. Claude가 시험 → 측정 → 저장·푸시 → 결과 요약까지 한다.

## 알아 둘 것
- 오래 걸린다(모델당 수십 분). 노트북 절전 모드를 끄고 둔다.
- 구독 사용 한도에 걸리면 멈추고 그때까지 결과를 올린다. 몇 시간 뒤 같은 방법으로 다시 실행하면 **안 끝난 모델만** 이어서 잰다.
- 이 PC에 `ANTHROPIC_API_KEY`가 있어도 실행 중에는 지운다(API 과금 방지).
- 데이터는 모두 합성(가상)이다. 외부로 나가는 것도 합성 데이터뿐이다.
- 결과는 `evals/results/model_check_v2/`에 쌓인다. 푸시가 끝나면 채팅에 "올렸어"라고만 알려 주면 성능점검표에 반영한다.
