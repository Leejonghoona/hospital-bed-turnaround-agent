병상 사이클 지도

한 병상을 두고 두 줄이 움직입니다. 왼쪽은 병상을 비우는 퇴원 줄, 오른쪽은 병상을 채우는 입원 줄이고, 가운데에서 병상을 다시 쓸 수 있게 만듭니다. 단계마다 누가 하는지, 시스템이 받는 사건, 에이전트가 할 일, 지금 개발 상태를 적었습니다. 시각과 소요시간은 현장 조사(병원 안내·QI 발표·간호사 글·영상)에서 가져왔고, 수치는 모두 합성 데이터 기준입니다.

에이전트가 끼어드는 자리

늦어지는 곳은 대부분 단계와 단계 사이의 넘겨주기입니다. 에이전트는 여기서 일합니다. 병상 선택과 숫자는 결정적 코드가 하고, 예외 때 정해진 행동 목록 중 무엇을 할지는 LLM이 판단하며 게이트웨이가 검사합니다(U8 확장, 결정됨).

  • 처방이 늦으면 미리 알림 · 심사가 다시 걸리면 예상 시각 재계산
  • 입실 시각이 급하면 침상 정리를 먼저 해 달라고 요청
  • 환자에게 안내한 시각을 지킬 수 있는지 판단, 어려우면 먼저 다시 연락
  • 늦게 온 격리 양성 결과: 진행 중인 배정·연락·청소를 되돌리고 접촉자 관리를 감염관리실에 올림
  • 내성균 이력이 있으면 근거를 붙여 알림, 격리 여부는 사람이 결정

개발 가능 범위

지금 바로

  • 당일 오전 배정 기본값, 통보형 병동 확인
  • 퇴원 순서 병행, 보호자 두 갈래, 희망 등급
  • 청소 두 갈래와 범위(다인실 침상 단위)
  • 격리 이력 알림, 늦은 양성 결과 되돌리기
  • 기간 10일과 현장값
  • 예외 판단 머리, 데모 장면 순서대로

현직자 답 뒤

  • 추출 라벨과 지연 사유 코드
  • 응급실발 입원
  • 청소 완료 입력자, 고위험군 기준
  • 퇴원~입실 구간 수요 확인

하지 않음

  • 청소·이송 인력 배정(범위 밖)
  • 병실 이동 연쇄 최적화(설계 항목)
  • 퇴원 예측 ML, 자체 현황판, 수술 연동
