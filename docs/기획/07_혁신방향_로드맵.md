# 07 혁신 방향과 로드맵 (2026-11-09, 사용자 결정 "A+B+C 전부")

엔드픽처에서 거꾸로 짠 로드맵이다. 이 문서의 순서대로 진행하고, 지적이 들어오면 이 문서를 먼저 고친 뒤 코드를 고친다.

## 정체성
**병상을 나누는 데서 끝나지 않고 만들어 내며, 병원에 스스로 맞추고, 자율권을 증명해 스스로 넓히는 병상 사이클 에이전트.**

| 층 | 무엇 | 기존 서비스와의 관계 |
|---|---|---|
| 1층(바닥) | 평범한 입원은 에이전트가 배정·확정·통보하고, 사람은 "확인 필요"만 본다 | 세종병원 AI 병상 배정과 같은 수준을 목표로 한다(첫 배정 자동화, 원무 메모 조건화, 자동 재배정). 차별점이 아니라 바닥 |
| A. 병상을 만든다 | 퇴원 쪽 병목(퇴원약·심사·수납·보호자·청소)을 에이전트가 감지하고 밀어서, 병상이 더 일찍 생기게 한다. 목표는 "입원 대기가 해소되는 시각"을 앞당기는 것 | 국내 공개 사례는 모두 입원 대기 → 배정(앞단)이다. 턴어라운드 추적·조율 사례는 찾지 못함(조사 기록 `docs/검토/AX수요/병원_AX_수요.md`) |
| B. 스스로 세팅된다 | 병원의 과거 배정·퇴원 기록을 넣으면, 그 병원의 숨은 규칙(진료과-병동 친화, 병실 등급 관행, 시간대)을 결정적 통계로 찾아 병원 프로필 초안을 만들고, 재생으로 "과거 사람 결정과 일치율, 안전 위반 0"을 보인다 | 세종병원은 병원 맞춤 개발. 데이터만으로 맞춰지는 사례는 찾지 못함 |
| C. 권한을 스스로 넓힌다 | 사람이 고친 기록(이의 제기, 직접 수정, 검토 결과)을 사례 유형별로 모아, 기준을 넘은 유형은 재생 증명을 붙여 "이 유형은 자동으로 올려도 된다"를 제안한다. 사람이 승인하면 정책이 바뀐다. 사고가 나면 자동으로 내린다 | 기존 서비스의 자동률은 고정된 숫자다. 이쪽은 운영할수록 오르는 곡선이고, 관문과 재생 평가가 그 증명 엔진이 된다 |

규칙 2(배정과 숫자는 결정적 코드)는 그대로다. B의 규칙 찾기와 C의 승격 판정은 결정적 통계이고, LLM은 설명과 예외 판단만 한다.
CLAUDE.md의 "2단계는 1단계를 마친 뒤"는 사용자 결정으로 B를 1단계 안에 넣는다(DECISIONS 같은 날).

## 마일스톤

| 단계 | 할 일 | 끝났다고 보는 기준 |
|---|---|---|
| M1 1층 | (1) 생성기 "현실 구성" 모드: 검토 사례를 고정 10건이 아니라 비율로 넣는다(값은 근거, 없으면 설계 가정) (2) 주기 자동 배정 루프(현장 프로필) (3) 에이전트 확정(완료, 153c282) (4) 지표 "일반 경로 처리율" = 사람 손 없이 확정까지 간 입원 비율, 사례당 사람 동작 | 데모 하루 재생, 시드 여러 개에서 처리율·사람 동작·실행 안전(S1·S2) 위반 0을 RESULTS에 적는다 |
| M2 A | 퇴원 단계별 소요 분포로 "늦어지는 퇴원"을 감지(예: 처방 미입력 09:00, 수납 지연, 보호자 미도착)하고, 에이전트가 정해진 행동(담당자 알림, 다음 단계 미리 요청, 퇴원 라운지 제안 등)을 고른다. 행동이 소요 시간에 주는 효과는 설계 가정으로 두고 민감도 분석을 함께 낸다 | 같은 시드에서 에이전트 끔/켬 비교: 퇴실 시각 분포, 정오 전 퇴실 비율, 입원 대기 해소 시각. 효과 가정값을 바꿔도 방향이 유지되는지 |
| M3 C | 사람 개입 기록 → 사례 유형별 일치율·이의율 → 승격 기준(사전 고정) → 재생 증명(과거 N일을 새 정책으로 다시 돌려 안전 위반 0, 사람 동작 감소) → 승격 제안 이벤트 → 사람 승인 → 정책 변경. 강등 규칙 | 시뮬레이션 30일: 자동률이 시간에 따라 오르는 곡선, 강등이 작동하는 시나리오 |
| M4 B | 숨은 규칙을 가진 합성 병원 여러 개로 과거 기록 생성 → 규칙 찾기 → 프로필 초안 → 재생 일치율 | 숨은 규칙 복원율, 생성된 프로필로 돌린 재생의 일치율과 안전 위반 0 |
| M5 모델 선정 | 역할별(추출, 예외 판단, 설명) 기준을 측정 전에 고정(`docs/검토/모델선정기준_설계.md`의 결정 규칙), 예외 판단 정답 세트를 200문항 이상으로, 천장 모델 → 비열등 → 비용 | 역할별 선정 표와 근거, 탈락 사유 |

M1 → M2 → M3 → M4 순서로 하고, M5는 M2와 나란히 한다(정답 세트 확장은 M2 행동 목록이 정해진 뒤).
