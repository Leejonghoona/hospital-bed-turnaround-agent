# 사용자·이해관계자 분석: 페르소나, RACI, 여정, 서비스 청사진

- 작성일: 2026-11-09. 상태: 초안, **가설**. 공개 자료와 설계 가정으로 만들었고 현직자 검증 전이다.
- 근거: SPEC POS-4(직무 목록), DECISIONS LP-25(배정 역할과 시간대), MA-01·MA-11(야간 역할), 설계 문서 "업무 재설계"·"사람 개입", `docs/검토/업무현실검증.md`, `docs/검토/스펙현실검증.md`, `docs/검토/현직자_질문지_검수.md` 1절(A1~A7).
- 형식 근거: ISO/IEC/IEEE 29148의 이해관계자 요구 명세(StRS)에 이해관계자 목록이 들어간다는 점, RACI(작업마다 A는 한 명), 서비스 청사진의 가시선(Shostack 1984, NN/g). 모두 검색 요약 수준(00 문서 2절).
- 페르소나는 직무 단위의 **가상 인물**이다. 실제 사람이나 병원을 본뜨지 않았다. 이름 대신 직무 코드를 쓴다.

## 결론 먼저

1. 주 사용자는 **병상관리 담당** 한 직무가 아니라 **시간대별 역할**이다. 주간은 원무 입원 파트, 야간·휴일은 당직 원무 또는 응급실 수납(LP-25, 야간은 설계 가정). 간호부가 배정하는 병원이면 이 문서 전체가 바뀐다(가정 A1).
2. 사람이 남는 세 순간의 **최종 책임자(A)**는 모두 사람이다. 공식 확정은 원무, 병동 수용 회신은 책임간호사, 안전 예외 사전 승인은 감염관리실. 에이전트와 게이트웨이는 어떤 작업에서도 A가 아니다.
3. 자동 실행(대기 정보 공유, 준비 시각 재추정, 청소 예정표 갱신, 청소 요청 발송)의 A는 **정책 파일을 승인한 사람**이다. 자동으로 돌아도 책임은 "자동으로 돌게 허락한 사람"에게 있다(설계 문서 "자동 범위 확대는 정책 변경 승인으로").
4. 환경 협력업체는 사용자지만 **환자 정보를 보지 않는** 사용자다. 병상 번호, 예상 시각, 청소 유형만 받는다(SEC-2).

## 2. 직무별 페르소나 (가상)

### P1. 병상관리 담당, 주간 (원무 입원 파트)
- **근거**: LP-25(공개 사례에서 배정은 원무 입원 파트, 입원 창구 평일 09~18시). 간호부 소속일 가능성은 가정 A1로 남김.
- **하루**: 아침에 퇴원 예정 목록과 입원 대기 명단을 맞춰 본다. 병동에 전화해 "몇 시쯤 비나요"를 묻는다. 정오 전후로 병상이 모자라면 입원 예정 환자에게 변경 연락을 한다.
- **목표**: 오늘 입원할 환자를 오늘 맞는 병상에 넣는다. 격리·성별·동명이인 실수를 하지 않는다.
- **고통**: 준비 시각을 모른다. 같은 병상을 두 번 약속할까 걱정한다. 승인할 건이 많아 예외에 집중하지 못한다.
- **WardLoop에서 원하는 것**: 근거, 대안 2개, 준비 시각 P90 변화, 승인 마감이 있는 검토 카드(설계 문서 "검토 카드"). 자기가 승인한 것과 시스템이 자동으로 한 것의 구분.
- **두려움**: 시스템이 대신 결정했는데 책임은 자기에게 오는 것. 형식적 승인(EVL-5 탐지 대상).

### P2. 병상관리 담당, 야간·휴일 (당직 원무 또는 응급실 수납)
- **근거**: LP-25, MA-11. 야간 배정 주체는 원문을 찾지 못함(설계 가정, A2).
- **차이**: 혼자서 응급 입원과 함께 처리한다. 주간 근무조의 미결 검토를 인계받는다(SAG-8).
- **원하는 것**: 인계 목록이 명확할 것, 마감 넘긴 건은 위로 올라갈 것(에스컬레이션).

### P3. 병동 책임간호사
- **근거**: 설계 문서 "수용 회신(책임간호사)", GW-4. 수용 회신 단계가 실제로 있는지는 가정 A5.
- **하루**: 근무조 인원과 중증 환자 수를 보며 입실을 받는다. 퇴원 환자의 보호자 도착, 퇴원 교육을 챙긴다.
- **원하는 것**: 입실 부하와 근무 인원 표시(화면 목업), 수용 불가 회신 시 사유만 남기면 재매칭은 알아서 될 것.
- **고통**: 전화가 많다. 받겠다고 했는데 환자가 바뀌는 것(그래서 철회 통지 `notify_ward`, LP-15).

### P4. 병동 간호사·간호조무사
- **근거**: 설계 문서 "침상 정리(간호조무사나 병동지원인력, 병원별 설정)", 추출 LLM 입력(전달사항, 보호자 통화 메모).
- **원하는 것**: 새 입력 칸이 늘지 않을 것. 전달사항에 쓴 "보호자 1시 넘어 온대요"가 그대로 반영될 것(AGT-5).
- **제품의 약속**: 자유 서술은 정해진 필드로만 추출되고 격리 판단에는 쓰지 않는다(SEC-3). 간호사가 "격리 해제"라고 써도 격리 판단은 주치의 오더 값만 쓴다.

### P5. 원무(수납·입원 확정)
- **근거**: 설계 문서 "HIS 확정과 입실 안내(원무)", GW-1 확정 직전 재확인.
- **원하는 것**: 확정 버튼을 누를 때 정보가 바뀌었으면 막아 줄 것(확정 직전 재확인, FHIR If-Match 버전 검사). 수납 대기가 길어지면 미리 알 것(SAG-5).
- **책임**: 공식 확정은 법적 책임이 있는 행위라 자동화하지 않는다(DECISIONS 엔드픽처).

### P6. 약제부 퇴원약 담당
- **근거**: `docs/검토/업무현실검증.md` Q1(입원환자 원내조제, 처방 발행이 조제 시작 조건), LP-27.
- **원하는 것**: 처방이 발행된 병상 중 다음 환자가 기다리는 병상 표시. 조제 순서는 약제부가 정한다.
- **제품이 하지 않는 것**: 조제 순서 결정. 처방 미발행 알림은 약제부가 아니라 병동(주치의 측)으로 간다(SAG-6).

### P7. 환경관리 협력업체 반장
- **근거**: CLAUDE.md 4번, SEC-2, 설계 문서 "환경(외부)".
- **원하는 것**: 전날 예정표, 실제 퇴실 시 한 번만 오는 확정 요청, 청소 유형(일반, 종말소독, 환기 대기, 아포 소독)이 분명할 것.
- **보지 않는 것**: 환자 이름, 진단, 사망 여부(MA-13).
- **미확인**: 완료 신호를 앱·버튼으로 보내는지, 전화로 알리는지(가정 A4). 전화라면 누군가의 입력 작업이 새로 생긴다.

### P8. 감염관리실 간호사 (야간은 감염내과 당직, 설계 가정)
- **근거**: GW-10(안전 예외 3단계), 질병관리청 표준예방지침 5.2.1·5.5.2.4·5.5.2.6(LP-24, 원문 확인).
- **원하는 것**: 결핵 방 공유 같은 금지는 아예 못 넘게. 공기주의 일반실, CRE 다인실은 사전에 묻게. 사후에 알게 되는 일이 없게.
- **고통**: 야간에 승인 요청이 오는데 대행 체계가 불분명하다(가정 A7). 현실에 없는 승인자를 두면 우회가 생긴다(스펙현실검증 "갸우뚱" 4번).

## 3. RACI (주요 작업별)

R = 실행, A = 최종 책임(행마다 한 명, 사람), C = 협의, I = 통보. "시스템"은 사가·에이전트·게이트웨이를 묶은 것이며 A가 될 수 없다.
열: 시스템 / 병상관리(P1·P2) / 책임간호사(P3) / 병동 간호(P4) / 원무(P5) / 약제(P6) / 환경(P7) / 감염관리(P8) / 주치의 / 정책 승인자.
정책 승인자는 정책 파일과 자율화 승격을 승인하는 사람이다(원무 책임 `admission_lead` 등, 병원별, 설계 가정).

RACI에서 나온 질문(현직자 확인 대상):
- "퇴원 예정 등록"의 A가 책임간호사인가 주치의인가. 등록 주체가 병동이라는 1차 근거(보령아산 안내)는 있으나 책임 소재는 확인하지 못했다.
- "청소 요청"의 A를 정책 승인자로 둔 것은 이 문서의 제안이다. 환경 부서장이 A여야 한다는 의견이 나올 수 있다.

### 4.2 다음 입원 환자·보호자의 여정 (간접 사용자)
제품 화면에 나오지 않지만 결과를 받는 사람이다. 환자 연락은 되돌릴 수 없는 분기점이다(SPEC 3절 2항).

| 단계 | 환자가 겪는 것 | 나쁜 순간 | 제품이 바꾸는 것 |
|---|---|---|---|
| 입원 예약 | 입원일 안내 | - | - |
| 입원 당일 오전 | 연락 대기 | 정오경 "오늘은 어렵다" 연락(서울아산 안내 1차) | 준비 시각 추정으로 더 이른 판단(효과는 미측정) |
| 연락 | 병실·시각 안내 | 안내 뒤 병실이 바뀜 | 연락 뒤 매칭은 자동으로 바꾸지 않고 담당 검토와 재연락 작업 생성(SAG-4) |
| 입실 | 병동 도착 | 침대가 준비 안 됨 | 확정 전 수용 회신과 종말소독 선행 조건(GW-4) |

## 5. 서비스 청사진 (퇴원 확정 → 다음 환자 입실)
