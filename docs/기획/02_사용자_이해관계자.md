- 작성일: 2026-11-09. 상태: 초안 v0.3(2라운드 검수 반영), **가설**. 공개 자료와 설계 가정으로 만들었고 현직자 검증 전이다.
- 근거: SPEC POS-4(직무 목록), DECISIONS LP-25(배정 역할과 시간대), MA-01·MA-11(야간 역할), MA-13·MA-15(사망·급변 전동), 설계 문서 "업무 재설계"·"사람 개입", `docs/검토/업무현실검증.md`, `docs/검토/스펙현실검증.md`, `docs/검토/병동사망_급변전동_조사.md`, `docs/검토/현직자_질문지_검수.md` 1절, `docs/검토/응급실범위/종합.md`, DECISIONS 2026-11-09 "응급실 범위"·"설계 문서 담당 검토 목록과 코드의 차이".
- 형식 근거: 29148의 이해관계자 요구 명세(StRS)에 이해관계자 목록이 들어간다는 점, RACI(작업마다 A는 한 명), 서비스 청사진의 가시선. 모두 검색 요약 수준(00 문서 2.2).
- 읽는 법: ID는 00 문서 0.1(페르소나 = PS-, 가정 = AS-·PA-, 사용자 스토리 = US-), 근거 표시는 00 문서 2.1을 따른다. 용어 풀이(사가, 멱등, SHACL, 홀드아웃, 뮤턴트, P10~P90, MAE 등)는 00 문서 0.3. 문장 끝의 표시: **[1차·원문]**, **[2차·요약]** 등은 출처, **(설계 가정)**은 근거 없음, **(현직자 확인 필요)**는 현장에서만 확인할 수 있는 것.
- 페르소나는 직무 단위의 **가상 인물**이다. 실제 사람이나 병원을 본뜨지 않았다.

## 결론 먼저

1. 주 사용자는 **병상관리 담당** 한 직무가 아니라 **시간대별 역할**이다. 주간은 원무 입원 파트다(LP-25, 공개 사례). 야간·휴일은 당직 원무인지 간호부 당직 감독인지 확인하지 못했다(설계 가정 AS-A2). 간호부가 배정하는 병원이면 이 문서 전체가 바뀐다(AS-A1).
2. 사람이 남는 세 순간과 최종 책임자(A)는 다음과 같다(00 문서 0.2). **공식 확정 = 원무, 환자 연락 = 원무, 안전 예외 = 감염관리실.** 병동 수용 회신(책임간호사)은 세 순간 밖의 다른 책임 개입이다. 에이전트와 게이트웨이는 어떤 작업에서도 A가 아니다.
3. **임상 판단과 행정 처리의 책임을 나눈다.**
   - 행정·운영 사유 7종(1인실 희망, 동명이인, 동의 미확인, 입력 누락, 병상 없음, 점수 근접, 격리 퇴실 병실 매칭)은 병상관리 담당(원무)이 A다. 격리 퇴실 병실 매칭은 다음 환자의 감염 상태가 아니라 "그 병실이 종말소독을 기다린다"는 운영 사실이고, 소독 확인 전 확정과 빈 병상 전환은 게이트웨이가 이미 막는다(GW-4·GW-6). 감염관리실은 I다.
   - 임상 사유 4종(격리, 선제 격리, 소아, 중환자실 하향)은 감염관리실(격리 계열) 또는 병동 수간호사(소아, 중환자실 하향)가 A다. 원무는 배정 처리(R)만 한다.
   - 이 분리는 이 문서의 제안이다(설계 가정 AS-E5, 현직자 확인 필요). 코드는 아직 검토 사유 11종을 모두 병상관리 담당에게 보낸다(04 PRD-Q9).
   - 설계 문서 담당 검토 표 중 3종(1급 감염병 전원 검토, 응급실 입원 대기, 낙상·섬망 고위험)은 코드 검토 사유에 없다. 낙상·섬망은 점수(간호사실 근처 가점)로만 쓴다(DECISIONS "설계 문서 담당 검토 목록과 코드의 차이", 06 결론 3).
4. 자동 실행(대기 정보 공유, 준비 시각 재추정, 청소 예정표 갱신, 청소 요청 발송)에서 **개별 건의 A**는 그 일이 원래 속한 직무다(예: 청소 요청 = 퇴실을 확인한 병동 책임간호사). **자동으로 돌게 한 규칙의 A**는 정책 승인자다(설계 문서 "자동 범위 확대는 정책 변경 승인으로"). 정책 승인자 역할은 코드·설정에 아직 없다(06 OP-03).
5. 병상은 퇴원 말고도 **병동 내 사망, 임종실 전실, 급변 전동, 자의퇴원**으로 빈다. 프로젝트 1단계는 이 넷을 구현했다(SAG-9, SAG-10). 원내 전동은 설계다. 응급실발 입원은 입원 대기의 정상 유입 경로인데 아직 경로를 구분하지 않는다. 얇게 넣기로 했고 시점은 설문·후속 질문 답 뒤다(DECISIONS "응급실 범위", 작업자 권고안). 응급실 내부 배치도는 제외, 응급실 대기 전체 판단은 확산 2단계다(4.4절).
6. 환경관리는 사용자지만 **환자 정보를 보지 않는** 사용자다. 소속(외주·자회사·직영)과 관계없이 병상 번호, 예상 시각, 청소 유형만 받는다(SEC-2).

## 2. 직무별 페르소나 (가상)

각 페르소나의 "하루"와 "고통"은 따로 표시하지 않으면 **설계 가정(현직자 확인 필요)**이다.

### PS-1. 병상관리 담당, 주간 (원무 입원 파트)
- **근거**: LP-25(공개 사례에서 배정은 원무 입원 파트, 서울대병원 입원 창구 평일 09~18시) [1차·원문]. 간호부 소속일 가능성은 AS-A1.
- **하루**: 아침에 퇴원 예정 목록과 입원 대기 명단을 맞춰 본다. 병동에 전화해 "몇 시쯤 비나요"를 묻는다(설계 가정). 병실이 모자라면 정오경 입원 예정 환자에게 변경 연락을 한다(서울아산 안내 [1차·원문]).
- **목표**: 오늘 입원할 환자를 오늘 맞는 병상에 넣는다. 격리 사례를 감염관리 판단 없이 확정하지 않는다. 성별·동명이인 입력 실수를 하지 않는다.
- **고통**: 준비 시각을 전화로 확인해야 하고 그 값이 자주 틀어진다. 같은 병상을 두 번 약속할까 걱정한다. 승인할 건이 많아 예외에 집중하지 못한다.
- **WardLoop에서 원하는 것**: 근거, 대안 2개, 준비 시각 P90 변화, 승인 마감이 있는 검토 카드(설계 문서 "검토 카드"). 자기가 승인한 것과 시스템이 자동으로 한 것의 구분.
- **두려움**: 시스템이 대신 결정했는데 책임은 자기에게 오는 것. 임상 판단의 책임까지 떠안는 것(R-41).
- **관련 스토리**: US-01, US-08, US-10a, US-14, US-16.

### PS-2. 야간·휴일 병상 조정 (당직 원무 또는 간호부 당직 감독, 병원별)
- **근거**: LP-25(창구 운영 시간 밖은 응급실 수납창구 [1차·원문]), MA-11, SPEC SAG-8. **야간에 누가 병상을 조정하는지는 원문을 찾지 못했다(설계 가정 AS-A2).** 간호부 당직 감독이 맡는 병원이 많다는 현장 의견이 있다(1라운드 현장 검수, 현직자 확인 필요). 응급실 수납 창구는 야간 입원 수속을 대행할 뿐, 검토 카드나 예외 판단을 맡는다고 보지 않는다.
- **차이**: 혼자서 응급실발 입원과 같이 처리한다. 주간 근무조의 미결 검토를 인계받는다(SAG-8).
- **원하는 것**: 인계 목록이 명확할 것, 마감 넘긴 건은 위로 올라갈 것(에스컬레이션). 안전 예외 대행 승인자에게 바로 닿을 것(AS-A7).
- **관련 스토리**: US-17.

### PS-3. 병동 책임간호사 (근무조)
- **근거**: 설계 문서 "수용 회신(책임간호사)", GW-4. 수용 회신 단계가 실제로 있는지는 AS-A5. 수용 판단 요인은 업무현실검증 Q3에서도 추정으로 표시했다.
- **하루**: 근무조 인원과 중증 환자 수, 같은 근무조의 다른 입실·수술 복귀 환자 수를 보며 입실을 받는다. 퇴원 환자의 보호자 도착, 퇴원 교육을 챙긴다(설계 가정).
- **원하는 것**: 입실 부하와 근무 인원 표시(화면 목업), 수용 불가 회신 시 사유만 남기면 재매칭은 알아서 될 것.
- **고통**: 전화가 많다. 받겠다고 했는데 환자가 바뀐다(그래서 병동 철회 통지, LP-15). 교대 시각(07·15·23시) 전후 입실은 부담이 크다(현직자 확인 필요, R-39).
- **관련 스토리**: US-12, US-24, US-26.

### PS-9. 병동 수간호사 (파트장)
- **근거**: MA-11의 상위 담당(수간호사·야간 감독)에 있다. 주간 입실 수용, 병상 잡아 두기, 사용 중지 협의를 근무조 책임간호사보다 수간호사가 정하는 병원이 많다는 현장 의견(1라운드 현장 검수, 현직자 확인 필요).
- **하루**: 병동 병상 운영과 인력 배치를 본다. 소아·중환자실 하향처럼 간호 부담이 큰 입실을 결정한다(설계 가정).
- **원하는 것**: 임상 사유 검토가 자기에게 오고, 원무는 결정 뒤 배정만 처리할 것. 급변 전동 뒤 원래 병상을 잡아 둘지 정할 수 있을 것(SAG-10의 병상 잡아 두기).
- **관련 스토리**: US-10b, US-25.

### PS-4. 병동 간호사·간호조무사
- **근거**: 설계 문서 "침상 정리(간호조무사나 병동지원인력, 병원별 설정)", 추출 LLM 입력(전달사항, 보호자 통화 메모).
- **원하는 것**: 새 입력 칸이 늘지 않을 것. 전달사항에 쓴 "보호자 1시 넘어 온대요"가 그대로 반영될 것(AGT-5).
- **제품의 약속**: 자유 서술은 정해진 필드로만 추출되고 격리 판단에는 쓰지 않는다(SEC-3). 간호사가 "격리 해제"라고 써도 격리 판단은 격리 오더 값(주치의 또는 감염관리실이 낸 오더, 오더 주체 필드 있음)만 쓴다.
- **미확인**: 병상 사용 가능 전환(HIS)을 병동이 입력하는지(AS-E4).
- **관련 스토리**: US-02.

### PS-5. 원무 (수납·입원 확정·환자 연락)
- **근거**: 설계 문서 "HIS 확정과 입실 안내(원무)", GW-1 확정 직전 재확인.
- **원하는 것**: 확정 버튼을 누를 때 정보가 바뀌었으면 막아 줄 것(확정 직전 재확인, HIS 버전 검사). 퇴원 진료비 심사가 언제 끝나는지 알 것(설계 가정, US-04).
- **책임**: 공식 확정과 환자 연락은 되돌리기 어렵고 책임 소재가 분명해야 하는 행위라 자동화하지 않는다(DECISIONS 엔드픽처). DECISIONS 엔드픽처는 "법적 책임"이라고 적었지만, 어느 법령이 HIS 입원 확정에 책임을 지우는지는 확인하지 않았다.
- **관련 스토리**: US-04, US-11, US-13.

### PS-6. 약제부 퇴원약 담당
- **근거**: `docs/검토/업무현실검증.md` Q1(처방 발행이 조제 시작 조건 [2차]), LP-27.
- **원하는 것**: 처방이 발행된 병상 중 다음 환자가 기다리는 병상 표시. 조제 순서는 약제부가 정한다.
- **제품이 하지 않는 것**: 조제 순서 결정. 처방 미발행 알림은 약제부가 아니라 병동으로 가고, 병동이 담당 의사에게 연락한다(SAG-6).
- **관련 스토리**: US-03(간접).

### PS-7. 환경관리 반장 (외주·자회사·직영, 병원별)
- **근거**: CLAUDE.md 4번, SEC-2, 설계 문서 "환경(외부)". 소속은 병원마다 다르다(현직자 확인 필요). 정보 최소화는 소속과 관계없이 적용한다.
- **원하는 것**: 전날 예정표, 실제 퇴실 시 한 번만 오는 확정 요청, 청소 유형이 분명할 것. 청소 유형은 **일반·종말소독** 두 가지이고, 추가 조건으로 **환기 대기(분)**와 **아포 소독**이 붙는다(SAG-2, 코드 기준).
- **보지 않는 것**: 환자 이름, 진단, 사망 여부(MA-13).
- **미확인**: 완료 신호를 앱·버튼으로 보내는지, 전화로 알리는지(AS-A4). 전화라면 누군가의 입력 작업이 새로 생긴다.
- **관련 스토리**: US-06.

### PS-8. 감염관리실 (감염관리 간호사, 실장. 야간은 감염내과 당직, 설계 가정)
- **근거**: GW-10(안전 예외 3단계), 질병관리청 표준예방지침 5.2.1·5.5.2.4·5.5.2.6(LP-24 [1차·원문, 제3자 사본]).
- **하루**: 격리 병실 배정 판단, 퇴실 병상 환경 점검, 다제내성균 동실자 감시(현직자 확인 필요). 감염관리 간호사가 권고하고 실장(감염내과 전문의)이 최종 판단하는 병원도 있어, A가 누구인지는 병원별 설정이다.
- **원하는 것**: 결핵 방 공유 같은 금지는 아예 못 넘게. 공기주의 일반실, CRE 다인실은 사전에 묻게. 사후에 알게 되는 일이 없게.
- **고통**: 야간에 승인 요청이 오는데 대행 체계가 불분명하다(AS-A7). 현실에 없는 승인자를 두면 우회가 생긴다(스펙현실검증 "갸우뚱" 4번).
- **관련 스토리**: US-07, US-09, US-10b, US-15, US-22.

### PS-10. 담당 의사 (주치의, 전공의, 진료지원 간호사)
- **근거**: 퇴원 결정은 전날 담당 의사가 한다(한양대 안내 [1차·원문]). 퇴원 처방을 실제로 입력하는 사람은 대개 전공의이고, 진료지원 간호사 제도화(간호법 시행)도 있다는 현장 의견과 보도가 있다(1라운드 현장 검수, [2차·요약]). 퇴원 처방이 진료지원 업무 목록에 드는지는 확인하지 못했다(현직자 확인 필요).
- **제품과의 관계**: 직접 쓰지 않는다. 처방 없음 알림은 병동에 가고, 병동이 담당 의사(전공의·진료지원 간호사)에게 연락한다.
- **관련 스토리**: US-03(간접).

## 3. RACI (구간별)

R = 실행, A = 최종 책임(행마다 한 명, 사람), C = 협의, I = 통보. "시스템"은 사가·에이전트·게이트웨이를 묶은 것이며 A가 될 수 없다.
**칸 배정은 대부분 이 문서의 제안(설계 가정)이다.** 근거가 있는 행만 근거 열에 출처와 수준을 적었다. "(병원별)"은 병원마다 달라 정책 파일의 역할 매핑으로 바꿀 값이다.

RACI에서 나온 질문(현직자 확인 대상, 05 3.6):
- 퇴원 예정 등록의 A가 수간호사인가 책임간호사인가. 전공의가 퇴원 예고 오더를 내는가.

- 임종실 전실은 주치의가 정하고 간호가 조율하는가.
- 병상 사용 가능 전환을 누가 HIS에 입력하는가. 격리 퇴실 청소를 감염관리실이 확인하는가(AS-E4).
- 급변 전동 뒤 원래 병상을 잡아 두는가, 누가 정하는가(AS-E3).

## 6. 검증 계획 연결
이 문서의 가정은 `docs/기획/05_리스크_가정_등록부.md` 3절에 모았다. 역할 가정(AS-A1·A2·A5·A6·A7)은 현직자 설문(`docs/검토/현직자_설문.html`, 매핑은 `docs/검토/현직자_질문지_검수.md` 5절)으로 확인한다. 설문은 발송됐고 답을 기다린다. 문항은 더 바꾸지 않는다(DECISIONS "현직자 설문 발송"). 설문에 없는 질문(비정규 경로 AS-E1~E3, 사용 가능 전환 AS-E4, 임상 사유 책임 AS-E5, 수간호사·야간 감독 역할, 응급실발 입원)은 답을 받은 뒤 보낼 후속 질문으로 적었다(05 3.6, `docs/검토/현직자_후속질문_응급실.txt`). 답이 오면 이 문서의 RACI와 페르소나를 먼저 고친다.
