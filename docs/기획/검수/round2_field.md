### 14. (02) C4: "격리 퇴실 병실에 매칭"까지 감염관리실 판단으로 보냈다
- **위치와 문장**: 결론 3 "임상 사유(격리 계열, 소아, 중환자실 하향)는 감염관리실 또는 병동 수간호사가 A", 3.3 "| 담당 검토: 임상 사유 ①격리 계열(격리, 선제 격리, 격리 퇴실 병실에 매칭) | 감염관리실 | ...". 04 US-10b "임상 사유 5종", 05 AS-E5도 같다.
- **문제**: `isolation_discharge_bed`는 다음 환자의 감염 상태가 아니라 "그 병실이 종말소독을 기다린다"는 운영 사실이다. 소독 확인 전 확정과 빈 병상 전환은 GW-4·GW-6가 이미 막는다. 이런 매칭을 건마다 감염관리실 결정으로 보내면 감염관리 간호사(주간 근무, 야간은 당직 자문, 스펙현실검증 1절 [추정])에게 병상 운영 일이 쏟아진다. 감염관리실은 "청소 순서 문제를 왜 우리가 정하나"라고 읽을 것이다 **[현직자 확인 필요]**.
- **고칠 방법**: `isolation_discharge_bed`를 행정·운영 사유로 옮긴다(A 병상관리 담당, I 감염관리실, 시스템이 소독 확인 전 확정 차단). 임상 사유는 4종(격리, 선제 격리, 소아, 중환자실 하향)으로 고치고 02 결론 3, 3.3, 04 US-10a·10b, 05 AS-E5, PRD-Q9를 같이 맞춘다. 판단이 서지 않으면 최소한 05 3.6 후속 문항 4번에 "격리 퇴실 병실(소독 대기)에 다음 환자를 정하는 것도 감염관리실이 보나요?"를 더한다.

### 15. (02) C4·C3: 임종실 전실 결정의 A와 사망 확인 행
- **위치와 문장**: 3.5 "| 임종실 전실 결정 | 책임간호사(수간호사가 정하는 병원은 수간호사, 병원별) | 병동 간호사 | 주치의, 가족 | ... | SAG-9, MA-13. A는 설계 가정 |", "| 사망 확인 | 주치의 | 담당 의사 | - | 책임간호사, 시스템(...) | SAG-10 |".
- **문제**: 임종실로 옮길지는 "임종이 임박했다"는 의학적 판단과 가족 설명이 먼저다. 간호는 임종실 배정·이동을 조율한다. 간호사가 A로 서면 병동 현직자는 "의사 판단 없이 간호사가 정하느냐"고 묻는다 **[현직자 확인 필요]**. 사망 확인은 야간이면 당직의가 하고, 사망을 처음 알고 의사를 부르는 사람은 병동 간호사인데 표에는 I로만 있다.
- **고칠 방법**: 임종실 전실 결정 = "A 주치의(야간 당직의), R 책임간호사·수간호사(임종실 사용 조율), C 가족, I 원무·시스템"(설계 가정 표시 유지). 사망 확인 = "A 주치의, R 담당 의사(야간 당직의), C 병동 간호사(발견·호출)". 근거 열에 저장소의 1차 원문을 더한다: 서울아산 장례식장 안내 "사망진단서 청구 → 이송 → 안치"(`docs/검토/스펙현실검증.md` 6절, 1차·원문). 지금은 조사 문서의 [2차·요약]만 달려 있다.

### 16. (02) C1·C6: 결론 3의 행정 사유 목록이 3.3과 다르다
- **위치와 문장**: 결론 3 "담당 검토 중 행정 사유(1인실 희망, 동명이인, 동의 미확인, 입력 누락)는 병상관리 담당(원무)이 A다."
