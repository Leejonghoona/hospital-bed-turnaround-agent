# 기획 문서 검수 채점 기준 (v1)

대상: docs/기획/00~06. 검수자는 문서마다 아래 6개 기준을 0~10점으로 매기고, 10점이 아니면 감점 이유와 고칠 곳(파일·절·문장)을 구체적으로 적는다. **만점 = 모든 문서의 모든 기준이 10점.**

| 기준 | 10점의 조건 |
|---|---|
| C1 사실 정합성 | 저장소의 정본(CLAUDE.md, 설계 HTML, SPEC.md, DECISIONS.md, RESULTS.md, 코드)과 모순이 없다. 숫자·ID·상태가 실제와 같다 |
| C2 완결성 | 그 산출물이 표준·모범 사례상 갖춰야 할 절이 빠짐없고, 00_기획산출물_분석.md가 약속한 내용을 다 담는다 |
| C3 근거와 표시 | 외부 주장에 출처가 있고 확인 수준(원문/검색 요약)이 표시돼 있다. 근거 없는 값은 "설계 가정", 수치는 "합성 데이터 기준 추정"으로 표시. 병원 발표 수치와 비교하지 않는다 |
| C4 현장 현실성 | 병원 현직자(간호·원무·감염관리)가 읽고 갸우뚱할 표현·절차가 없다(CLAUDE.md 7번) |
| C5 명료성 | 결론 먼저, 쉬운 한국어, 짧은 문장, 용어 일관, 표가 읽기 쉽다 |
| C6 문서 간 일관성 | 문서끼리 ID(G·US·R·A·Q·IF 등), 용어, 범위, 수치가 서로 맞는다. 설계에서 "설계/제외"인 것을 구현 범위로 쓰지 않는다 |
