### 2. 1.1 ⑤ "EVL-4 중단"이 5절의 EVL-4 "예정", SPEC EVL-4, 평가표 P4, PRD-Q8 "해결"과 어긋난다 (C6: 04, 03)

- 문제:
  - SPEC EVL-4는 지금도 "규칙 모드 대비 에이전트 비교(P4), 모델 비교(M1) … `예정`"이다. 평가표 P4는 "보고(같아도 그대로)"다. 중단된 것은 긴 테스트 `rule_mode_vs_agent` 하나(P4 쪽)이고, M1은 1.1 ③으로 남아 있다. 그런데 ⑤는 EVL-4 전체가 중단된 것처럼 읽히고, 같은 문서 5절은 EVL-4를 "예정"으로 둔다.
  - RESULTS는 P4가 U8 뒤 "정의상 같다"고 적었다. 그렇다면 SPEC EVL-4와 평가표 P4는 U8에 아직 맞춰지지 않았다. 그래서 PRD-Q8의 "해결"과 03 INT-Q6의 "EVL-4도 U8에 맞춰 고쳤다"가 지금은 반만 맞다.
  - 측정 계획을 멈춘 이유는 RESULTS에만 있다. DECISIONS에 항목이 없다(CLAUDE.md 작업 방식: 설계와 다르게 할 이유는 DECISIONS에 먼저).

  - 04 5절 평가 행의 "예정" 칸을 "4(P4 긴 테스트 중단, M1은 1.1 ③)"로 바꾼다.
  - 04 10절에 PRD-Q14를 더한다: "SPEC EVL-4와 평가표 P4를 U8 뒤 어떻게 둘까. (가) '정의상 같음'으로 보고 (나) P4 삭제 (다) `select` 모드 대비로 다시 정의. 누가: 사용자. 영향: SPEC EVL-4, 평가표 P4, 1.1 ⑤. 상태: 열림(DECISIONS에 먼저 적음)."
  - 03 INT-Q6 끝 문장 뒤에 덧붙인다: "다만 EVL-4의 규칙 모드 대비(지표 P4) 긴 테스트는 U8 뒤 두 모드가 정의상 같아 중단했고, SPEC·평가표를 어떻게 고칠지는 04 PRD-Q14에서 정한다."
