## 반영하지 않은 것과 남은 일

1. **RESULTS 기록**: 기준선 재측정, 사람 부담, 홀드아웃 추정, 안전 스윕(시드 0~999)을 RESULTS에 쓰는 일. 이 폴더 밖이라 하지 않았다(04 PRD-Q12).
2. **평가표 I1 합격 기준 개정**: PRD에는 두 기준을 함께 적었고 평가표 파일은 고치지 않았다.
3. **SPEC AGT-3·EVL-4 문구 개정**: SPEC 동결 뒤 변경 절차가 필요해 열린 질문(PRD-Q8)으로만 남겼다.
4. **현직자 설문 문항 추가**: 설문 파일은 작업 범위 밖이다. 05 3.6에 후속 인터뷰 문항 후보로 적었다.
5. **임상 사유 검토 수신자 분리(코드)**: 문서에서 설계 가정으로 제안만 했다(PRD-Q9).
6. **검수자가 찾은 외부 출처**(분당서울대 알림톡, 사후 간호 연구, 퇴실 병상 환경감시 연구, 진료지원 간호사 보도 등): 작업자가 원문을 열지 않았다. 인용한 곳은 "1라운드 현장 검수가 찾음, 확인 필요" 또는 검수자의 표시 수준(요약)으로 적었다. 신속대응시스템·응급실 재실시간 보도는 문서에 인용하지 않았다.
