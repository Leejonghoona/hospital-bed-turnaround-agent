# 기획 문서 검수 1차: 현장 현실성(C4)·근거 표시(C3) 관점

- 검수일: 2026-11-09. 대상: `docs/기획/00~06`. 기준: `docs/기획/검수/채점기준.md` v1(C1~C6, 각 0~10).
- 검수자 관점: 상급종합병원 병동 수간호사 8년, 입원 원무 팀장 5년, 감염관리실 협업 경험을 가진 현장 전문가(가상 역할). C4와 C3를 깊게 보고, C1·C2·C5·C6은 이 관점에서 눈에 띈 것만 적었다.
- 근거 표시: **[1차·요약]** 병원 안내·정부 발표를 검색 요약으로만 확인(원문 미대조) / **[2차·요약]** 기사·논문을 검색 요약으로만 확인 / **[저장소]** 이 저장소 문서에서 확인 / **[현직자 확인 필요]** 검수자 현장 경험에서 나온 지적이며 공개 근거를 찾지 못함. 이번 세션은 사이트 직접 열기를 하지 않았고, 모든 외부 근거가 검색 요약 수준이다.

한 줄 총평: 형식(StRS, RACI, 청사진, 위험 로그)은 잘 갖췄고 "설계 가정" 표시 습관도 좋다. 그러나 **병상이 비는 경로를 "정규 퇴원" 하나로만 그렸다.** 현장에서 병상이 갑자기 비거나 막히는 경로(병동 내 사망, 임종실 전실, 중증 악화로 인한 중환자실 급변 전동, 원내 전동, 전원, 자의퇴원, 응급 입원 끼어들기)가 02 여정·RACI·청사진과 05 등록부에 없다. 이미 구현된 사망 경로(SAG-9, MA-13)조차 사람 쪽 문서에 나오지 않는다. 또 원무 직원에게 임상 판단 책임을 지우는 RACI 칸이 몇 개 있어, 간호부와 감염관리실 현직자가 먼저 걸고 넘어질 것이다.

## 공통 지적 (여러 문서에 걸침)

### X-1. 비정규 병상 경로 누락 (C4, C2) — 02·04·05·06 전부
- **위치**: 02 4.1 여정("전날 17:00 ~ 18:00 교대"), 02 5절 청사진 "퇴실 전 (퇴원 확정 → 퇴실)", 02 3절 RACI 행 목록, 05 1절 R-01~R-34, 04 4절 US-01~US-23.
- **문제**: 사례가 모두 "퇴원 결정 → 퇴원약·수납 → 퇴실 → 청소 → 입실" 한 줄이다. 현장의 병상 수급은 아래 경로가 같이 흔든다.
  1. **임종실 전실**: 2024-08-01부터 새로 여는 300병상 이상 종합병원과 요양병원은 임종실 1개 이상, 기존 기관은 1년 유예 뒤 설치 의무 [1차·요약: 보건복지부 발표 보도, 메디게이트·국민일보·메디칼타임즈 2024-07]. 저장소는 이미 SAG-9·MA-13·DAT-10으로 구현했다 [저장소]. 그런데 02의 페르소나·RACI·여정·청사진 어디에도 사망 경로가 없고, 04에도 해당 사용자 스토리가 없다(04 5절 표 "사망·임종실"이 기능 묶음 이름으로만 나온다).
  2. **병동 내 사망(임종실로 못 옮긴 경우)**: 급사, CPR 실패, 임종실 사용 중, 다인실 커튼 안 임종. 이때 병상은 사망 선언 → 사후처치 → 가족 임종 면회 → 장례식장(영안실) 이송 순서를 거쳐야 빈다. 국내 성인 사후 간호 프로토콜 연구는 단계를 "사망 확인·보고, 시신 간호, 가족 임종 면회, 이송, 기록"으로 정리했다 [2차·요약: 한국 간호학 논문 2023, koreascience JAKO202317154013350]. 병원 장례식장 안내는 "원내 사망 시 사망진단서 발급 → 이송·안치 → 장례식장 접수"를 안내한다 [1차·요약: 서울아산병원 장례식장 안내]. MA-13은 "임종실 전실 시각 = 병상이 빈 시각"만 정의했다. **병동 내 사망 시 병상이 비는 시각(영안실 이송 시각)과 그 사이 다른 환자 배정 금지**는 저장소 어디에도 없다 [저장소: DECISIONS MA-13, LP-28 확인].
  3. **임종실 전실 뒤 원래 병상 처리**: 임종실 체류가 며칠 이어지거나, 상태가 나아져 돌아오거나, 유족이 짐을 가지러 오는 일이 있다. 원래 병상을 전실 즉시 재배정해도 되는지, 일정 시간 보류하는지는 병원 규칙이다 [현직자 확인 필요]. 지금은 "전실 즉시 청소 요청"이 고정이다.
  4. **중증 악화 → 중환자실 급변 전동**: 신속대응시스템(RRS)은 300병상 이상 종합병원·상급종합병원 대상 시범사업이 2019년부터 3단계까지 진행됐고 2027년 본사업 전환을 앞두고 있다 [2차·요약: 메디게이트뉴스 2026-10]. 급변 전동은 **퇴원 예정 없이 병동 병상이 비는** 대표 경로이고, 반대로 중환자실 하향 전동 환자(DAT-6 검토 사례)가 병동 병상을 요구한다. 병원에 따라 중환자실로 간 환자의 원래 병상을 일정 시간 비워 두는 관행이 있다 [현직자 확인 필요]. 정오 가용 병상 추정(8단계)이 이 경로를 모르면 비계획 공실과 비계획 수요를 둘 다 놓친다.
  5. **원내 전동·전실**: 분당서울대 스누워드가이드는 "병상별 가용 전환 여부와 입·퇴원 현황, 전실·전동 현황"을 한 화면에 보인다 [2차·요약: 데일리안 2026-06, 저장소 업무현실검증 Q2에도 인용]. 전동은 "비우면서 차지"하는 사례라 GW-15로 "설계"에 두었다 [저장소: SPEC GW-15]. 범위 밖이면 02·04 비목표에 이유와 함께 적어야 하는데 빠져 있다.
  6. **전원(요양병원·타 병원)과 자의퇴원**: 전원은 받는 병원 확정·구급차(이송 차량) 시각에 묶여 퇴실이 늦는 흔한 사유다. 상급종합병원 장기재원 환자의 전원 결정 요인을 분석한 국내 논문이 있다 [2차·요약: koreascience JAKO202414447327753]. B4 지연 사유에 "전원"이 있지만 [저장소: 현직자_질문지_검수 B4], 02 이해관계자에 **진료협력센터(회송·전원 담당)**가 없다. 자의퇴원은 SAG-9에 있으나 02·04에 없다.
  7. **응급 입원 끼어들기**: 상급종합병원의 병상 수요는 정규 입원만이 아니다. 응급실 재실시간은 응급의료기관 평가 지표이고 2027년부터 산정 방식이 중앙값으로 바뀐다 [2차·요약: 데일리메디 2026-10]. 야간에 응급 입원이 사전 매칭된 병상을 먼저 차지하는 일이 일상이다 [현직자 확인 필요]. 설계는 응급실 입원 대기를 "확산 2단계"로 뺐지만 [저장소: 설계 문서 "인접 공정"], **정규 사례가 응급 입원과 같은 병상을 다툰다는 사실**은 1단계 여정과 리스크에 있어야 한다.
- **고칠 방법**:
  - 02에 "4.3 병상이 비는 비정규 경로" 표를 더한다. 열: 경로 / 병상이 비는 시점 / 관여 직무 / 1단계 처리(구현·설계·범위 밖) / 근거. 행: 임종실 전실(구현, SAG-9), 병동 내 사망(미정, 새 가정), 중환자실 급변 전동(범위 밖, 가용 추정 오차 원인으로 표시), 중환자실 하향 전동 수용(검토 사례로 구현, DAT-6), 원내 전동(설계, GW-15), 전원(지연 사유만), 자의퇴원(구현, SAG-9), 응급 입원 끼어들기(범위 밖, 리스크로).
  - 02 RACI에 "사망" 구간 행을 더한다: 사망 선언(주치의 A/R), 사후처치·임종 면회(책임간호사 A, 병동 간호 R), 임종실 전실 결정(책임간호사 A, 주치의 C, 원무 I), 장례식장 이송(장례식장·이송 R, 책임간호사 A), 사망 퇴원 수납(원무 A/R), 병실 청소 요청(시스템 R, 사망 여부는 싣지 않음).
  - 05에 새 리스크(아래 05 절 R-35~R-44 제안)와 새 가정(병동 내 사망 시 병상이 비는 시각, 임종실 전실 뒤 원래 병상 보류 여부, 급변 전동 병상 보류 관행)을 더한다.
  - 04 비목표에 "원내 전동·중환자실 전동 사가(GW-15, 설계)"를 이유와 함께 넣고, US-24로 "책임간호사로서 환자가 임종실로 옮기면 원래 병상의 청소가 바로 요청되고, 보호자에게 수납·퇴원 독촉 경보가 가지 않기를 원한다(SAG-9)"를 더한다.

### X-2. 원무 직원에게 임상 판단 책임을 주는 RACI 칸 (C4)
- **위치**: 02 3절 "입실 | 담당 검토(검토 등급) | … | 병상관리 **A/R** | … | 감염관리 C(격리 사례)", 02 P1 "목표: … 격리·성별·동명이인 실수를 하지 않는다", 03 보도자료 "격리, 소아, 동명이인처럼 제가 봐야 하는 건만"(P1 = 원무 입원 파트).
- **문제**: 원무 입원 파트 직원은 행정직이다. 격리 사례(공기주의, CRE, 선제 격리), 소아, 중환자실 하향, 낙상·섬망 고위험의 배치 적절성에 대해 최종 책임(A)을 지는 것은 현장에서 받아들여지지 않는다. 현실에서 원무가 하는 일은 "빈 병상 확인과 배정 처리"이고, 격리실 우선순위는 감염관리 실무자가 정한다(지침 5.2.1, 저장소 스펙현실검증 "갸우뚱" 2번에 이미 기록) [저장소]. 임상 판단이 섞인 검토의 A는 병동 수간호사·책임간호사 또는 감염관리실이어야 하고, 원무는 R(처리)이다 [현직자 확인 필요: 병원별 차이 큼].
- **고칠 방법**: "담당 검토"를 사유별로 나눈다. ① 행정 사유(1인실 희망·차액 동의, 동명이인 표시, 통합병동 동의 미확인, 성별 누락): 원무 A/R. ② 임상 사유(격리·코호트·선제 격리, 중환자실 하향, 소아, 낙상·섬망): 감염관리실 또는 병동 수간호사 A, 원무 R(배정 처리). 02 P1의 "목표"에서 "격리 실수를 하지 않는다"는 "격리 사례를 감염관리 판단 없이 확정하지 않는다"로 바꾼다. 이 분리가 맞는지 A1 설문 문항에 덧붙인다.

### X-3. 직무 이름과 빠진 직무 (C4)
- **위치**: 02 1절 이해관계자 지도, 2절 페르소나 P1~P8.
- **문제와 근거**:
  - **병동 수간호사(파트장·UM)**가 없다. 근무조 "책임간호사(charge nurse)"만 있다. 주간 입실 수용, 병상 보류, 병실 사용 중지 협의, 정책 승인 같은 일은 근무조 책임간호사보다 수간호사가 결정하는 경우가 많다 [현직자 확인 필요]. 02 RACI의 "퇴원 예정 등록 A = 책임간호사", "병실 사용 중지 C = 책임간호사"는 수간호사 몫일 가능성이 크다.
  - **간호부 야간 당직(감독간호사·당직 수간호사)**이 없다. 야간 병상 조정과 응급 입원 병동 배정을 간호부 당직이 맡는 병원이 많다 [현직자 확인 필요]. 05 A2가 이 가능성을 가정으로는 두었지만, 02 P2는 "당직 원무 또는 응급실 수납"을 사실처럼 썼다. 특히 **"응급실 수납" 직원이 검토 카드·예외 판단을 한다**는 그림은 현장에서 가장 어색하게 읽힌다.
  - **전공의·진료지원 간호사(PA)**가 없다. 퇴원 처방을 실제로 입력하는 사람은 대개 주치의가 아니라 전공의이고, 2024년 전공의 이탈 뒤 진료지원 간호사가 일부 진료 업무를 맡았으며 간호법 시행(2025-06)으로 진료지원업무가 제도화됐다(행위 목록 43개, 2026-07 고시) [2차·요약: 머니투데이 2025-05·2026-07, 뉴시스 2024-08]. 퇴원 처방이 진료지원 업무 목록에 드는지는 확인하지 못했다 [현직자 확인 필요]. 02 RACI "퇴원 처방 발행 | 주치의 A/R"은 R이 비현실적이다. "처방 없음 알림"의 수신자도 주치의가 아니라 담당 전공의·PA다.
  - **진료협력센터(회송·전원), 의료사회복지팀(무연고·의료비 지원으로 퇴원 지연), 장례식장, 시설팀(음압실 고장), 보험심사팀(퇴원 진료비 심사)**이 이해관계자 지도에 없다. 02 청사진 백스테이지에 "원무 진료비 심사"가 있는데, 심사는 원무가 아니라 보험심사팀(심사 간호사 포함)이 맡는 병원이 많다 [현직자 확인 필요]. 한양대병원 안내는 "퇴원일 오전 진료비 최종심사 후 문자"까지만 말한다 [저장소: 업무현실검증 Q1, 1차].
  - **이송팀**을 "제외"로만 두었다. 인력 배정은 범위 밖이 맞지만(CLAUDE.md 4번), 휠체어·침대 이송, 응급실 → 병동 이송, 시신 이송은 퇴실·입실 시각을 정한다. RACI에서 아예 열을 없애면 "누가 환자를 옮기나"가 비어 보인다.
- **고칠 방법**: 이해관계자 지도에 위 직무를 "간접" 또는 "의존"으로 더하고, RACI에 "의존(범위 밖)" 열을 하나 두어 이송·장례식장·진료협력센터를 I로라도 적는다. P2는 "야간·휴일 병상 조정(간호부 당직 감독 또는 당직 원무, 병원별)"으로 이름을 바꾸고 "응급실 수납"은 "입원 수속 창구 대행"으로만 남긴다. P3 옆에 "P3a 병동 수간호사"를 둔다.

### X-4. "준비 완료"를 누가 확인하는가 (C4, C2)
- **위치**: 02 RACI 병상 준비 구간(퇴실 처리, 청소 요청, 청소·소독 수행, 침상 정리), 02 청사진 "완료 신호 추적", 06 IF-07 "들어옴: 청소 시작·완료 신호".
- **문제**: 청소 업체의 "완료"와 병상의 "사용 가능 전환"은 다른 사건이다. 현장에서는 병동 간호사(또는 간호조무사)가 침상 정리와 비품을 확인하고 HIS 병상 상태를 바꾸는 경우가 많다 [현직자 확인 필요]. 격리 퇴실 병실은 감염관리실이 퇴실 병상 환경을 직접관찰·형광표지로 점검하는 병원도 있다(국내 대학병원 연구, 퇴실 병상 942곳 평가) [2차·요약: koreascience JAKO202419475581098]. RACI에 "병상 사용 가능 전환(HIS)"과 "격리 퇴실 병실 청소 품질 확인" 행이 없다. 이 행이 없으면 가드레일 S2(종말소독 누락 0건)가 "업체 완료 신호"만으로 판정된다는 사실이 가려진다.
- **고칠 방법**: RACI에 두 행을 더한다. "사용 가능 전환: 병동 간호 R, 책임간호사 A, 시스템 C(종말소독 선행 조건 검사)", "격리 퇴실 청소 확인: 환경 R, 감염관리 A 또는 C(병원별)". 05 가정에 "준비 완료 = 업체 완료 신호인가, 병동 확인인가"를 A3·A4 옆에 새 번호로 둔다.
