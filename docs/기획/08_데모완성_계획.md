# 08 데모 기준 100% 완성 계획 (2026-11-09 사용자 승인)

- 2026-11-09 최신화: 무엇이 바뀌었나. 날짜 표기(제목의 승인일)를 다음 날로 적었던 것을 2026-11-09로 고쳤다(같은 날 작업). 1~5단계는 모두 끝났다. 결과와 남은 일은 `docs/가이드/데모_가이드.md` 4·7절과 07 문서 "엔드픽처 기준 현황"에 있다. 이 계획 본문은 그대로 둔다.

## 데모 기준 100%의 정의 (합성 데이터로 증거와 함께 시연)
1. 퇴원 결정 → 다음 환자 입실 전 구간이 재생되고 구간마다 에이전트·게이트웨이가 동작한다.
2. 예외 10종 모두 감지 → 판단 → 검사 → 실행 경로가 있고 정답 세트로 측정한다.
3. 사람은 책임 순간에만 개입하고 그 비율과 사람 동작 수를 잰다.
4. 처음 보는 병원 데이터 형식이 온보딩 → 재생 증명 → 운영 적용까지 한 번에 간다.
5. 역할별 화면에서 시연 대본 3장면을 클릭으로 재현한다.
6. 실행 상태 안전 위반 0(시드 50개), 홀드아웃·회귀 통과.
7. 결정·결과·데모 가이드 문서.

외부 대기(100% 산정에서 뺌): 현직자 설문 반영, 시나리오 라벨 재승인.

## 진행 방식
단계를 끝내면 커밋하고 관련 비판 페르소나 3~4명에게 다중 에이전트 검수를 맡긴 채 다음 단계를 시작한다. 검수 결과의 안전·정확성 문제는 즉시 고치고 나머지는 `docs/검토/단계검수/`에 기록한다. 단계마다 사용자에게 요약 보고.

## 단계
| 단계 | 내용 | 끝난 기준 | 검수 페르소나 |
|---|---|---|---|
| 1 사이클 완성 | 입실 구간(병동 준비 → "올려주세요" → 입실), 현장형 퇴원 순서(심사·조제 병행 → 수납 → 영수증 → 약 전달·교육), 청소 두 갈래와 병실 종류별 입실 가능 기준, 당일 오전 일괄 배정 시점 | 전 구간 재생, 입실까지 대기 지표, 재측정 안전 0 | 병동 책임간호사, 원무 배정 담당, 감염관리·환경 실무자, 시뮬레이션 방법론 |
| 2 예외 판단 완성 | 남은 예외 5종, 단계별 허용 목록, P90 도구값, Sonnet·Opus 결과 뒤 프롬프트 개정·모델 결정 반영 | 예외 10종, 운영 입력으로 세트 측정, 금지 0 | 환자안전, 원무 실무, 평가 통계, 현직 간호사 |
| 3 온보딩 흐름 | 업로드 → 매핑·질문(구조 → 형식 → 열 → 코드표) → 답 → 절차 추론 → 프로필 → 재생 증명 → 승인 → 버전 고정 → 변화 감지·재질문, 학습 고리(회귀 관문 뒤 공용 사전), 진료과→병동 사용 | 새 형식 병원 한 번에 운영까지, 질문 수 학습 곡선, 틀린 값 0 | 의료정보팀, 개인정보·거버넌스, 온톨로지 설계, LLMOps |
| 4 화면 | 역할별 화면(원무, 병동, 감염관리실, 관리자 승격 카드, 온보딩 질문), 대본 3장면 클릭 재현, 화면 자동 시험 | 대본 3장면 재현, 스크린샷 시험 | 실사용자 3명, UX, 병원 경영진 |
| 5 통합 증명·기본값 전환 | 현장값 기본 전환(바뀐 라벨 초안·옛 판 회귀), 최종 설정 재측정, 50시드 안전, 자율화 증빙 묶음, 데모 가이드 | 전체 회귀, 최종 수치, 외부 대기 목록 | 비판적 PM, 안전 감사, 재현성, 현직자 |

완성 뒤: 기획용 양식에 가까운 포트폴리오와 이력서(개발용·기획용 참고)를 고치고 전문 다중 에이전트 검수 → 수정을 만점까지 반복한다. 개인 문서는 저장소에 올리지 않는다.
