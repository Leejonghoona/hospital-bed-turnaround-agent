## 3. 시나리오별 변경 요약 (1라운드 대비 바뀐 것만)

- **A01**: 분리 대신 fixture 모드 두 개(injected_proposal 유무)로 한다. P1을 남성으로 보강한다.
- **A02**: 변경 없음. 초안에 must를 추가하라는 요구만 명시한다.
- **A03**: 검토 범위를 "같은 병동"으로 DECISIONS에 올린다. 라벨은 그대로 review이고, 대안 2개가 붙은 검토 카드(H2)를 건다.
- **A04**: 상황에 수용 회신 완료를 보강한다.
- **A05**: override_param을 철회하고 `params.overridden_from=general`로 남긴다.
