# 회귀 시나리오 라벨 토론 결과 (v1)

- 일시: 2026-11-08
- 목적: 라벨 30개를 기초부터 다시 검토한다(사용자 요청).
- 참가자: 토론 에이전트 3명. 병상관리 실무(간호·원무 15년), 감염관리·환자안전(감염내과, 격리 병상 운영), 평가 설계(규제 산업 eval).
- 한계: 참가자가 모두 Claude 계열이라 같은 계열 편향이 있을 수 있다(평가표 원칙 4, 검수 G13). 이 토론은 사용자 승인을 대신하지 않는다. 라벨은 모두 `draft`이고 사용자가 승인해야 확정된다.

## 진행 방식
1. **1라운드, 블라인드 도출**: 참가자에게 상황 설명(`docs/라벨토론/situations.md`)과 설계 문서만 주었다. 작업자 초안은 보여 주지 않았다. 각자 30개 정답을 처음부터 도출했다. 원문: `round1_ops.md`, `round1_safety.md`, `round1_eval.md`.
2. **2라운드, 토론**: 블라인드를 풀고 다른 두 참가자의 1라운드 결과와 작업자 초안(`draft_labels_v0.md`)을 읽게 했다. 갈리는 곳마다 양보하거나 설계 근거로 반박하게 했고, "다수 의견이라는 이유만으로 따르지 말 것"을 조건으로 걸었다. 원문: `round2_*.md`.
3. **정리**: 작업자가 합의를 라벨 v1에 반영했다. 2:1이거나 표현만 다른 곳은 근거를 적어 판정했다. 설계 공백을 메운 전제는 `docs/DECISIONS.md`의 LP-01~15로 올렸다.

## 블라인드 단계에서 셋이 독립적으로 같은 결론을 낸 것
- 공기감염 격리는 음압실만, 접촉 격리는 음압실 또는 1인실이다. 초안도 같았다.
- 1단계에서는 병동 확인과 담당 검토가 같은 사람 개입 3회라 H1로 등급을 구별하지 못한다.
- 상황 정보 부족으로 정답이 하나가 아닌 시나리오가 있다(음압실 공실, 후보 병상, 버전 변경 내용).
- 초안 F04 Q2의 `refuse_query`는 틀렸다. 권한 거부와 섞인다.
- 아무 일도 안 하는 시스템이 통과할 수 있는 라벨이 있다(A02, A04, E03, C01).
