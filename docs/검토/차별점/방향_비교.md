# 차별점 방향 비교 (2026-11-09)

근거: `현장문제.md`(현장 문제 발굴), `에이전트혁신.md`(에이전트 혁신), `비평.md`(비평가). 세 검토 모두 같은 진단에서 출발한다: 첫 배정 추천, 병상 현황판, 청소 앱, 퇴원 예측, 자유 서술 추출은 이미 상품이다(Epic, 분당서울대 스누워드가이드, 아산·길·세종·중앙대광명 자동 배정, 이지케어텍 Medical OS, Epic Agent Factory).

## 세 검토가 겹치는 지점
- **안전을 증명하는 실행 관문**: 시스템이 실제로 한 행동을 다시 돌려 검사하는 증명(실행 S1 0/410, S2 0/58, 장치 끄기 14/14)은 드물다(비평, 혁신). 병상을 움직이는 AI가 늘수록 "누가 검증하고 감시하고 끄느냐"가 빈 자리다(혁신: 세종병원 자동 배정이 HIS에 자동 반영, AI 기본법 제34조, 아산 AI혁신지원실).
- **늦게 도착하는 안전 정보**: 격리 등록 53%(QIH 원문). 격리를 확정/없음/아직 모름으로 다루고, 늦게 온 오더가 이미 진행된 배정·연락·청소에 닿으면 되돌린다(현장 D, 혁신 3순위, 비평 "나쁜 날" 장면 1).
- **"왜 늦나, 그때 알 수 있었나" 설명**: 사건 기록에서 임계 경로를 찾고 그 시점에 알 수 있던 정보로 다시 본다(혁신 4순위, 현장 C).
- U8(병상은 규칙이 고르고 LLM은 설명)은 약점이 아니라 이 차별점의 기반이다. LLM은 귀(입력: 메모·인계·전화 메모에서 신호), 입(설명), 시험관(시나리오 생성·평가)을 맡는다.

## 방향 후보
| | 1. 검증 가능한 실행 관문 | 2. 약속 원장 | 3. 둘을 묶은 "나쁜 날을 막는 관문" (추천) |
|---|---|---|---|
| 한 줄 | 누구의 배정 AI·RPA든 그 앞에 서서 위험한 실행을 막고, 막았다는 증거를 낸다 | 전화·메모로 오가던 요청과 약속을 기록하고 기한·주인을 정해 지키게 한다 | 관문이 중심, 대표 장면은 "나쁜 날 3개", 귀(메모 신호)와 입(지연 설명)을 붙인다 |
| 누가 반기나 | 병원 AI 도입 승인 부서, CIO, 감염관리실, 채용 심사자(안전·신뢰성) | 원무 배정 담당, 병동 책임간호사 | 1의 대상 + 감염관리실·병동 |
| 근거 | 판결·인증·AI 기본법·자동 배정 사례(원문), 우리 실행 안전 증명 | 아산 하루 250건 요청, 퇴원 252.5분(한 병원 값), 블로그·영상 | 둘 다 |
| 3분 데모 | 같은 하루를 "상용 제품 공개 동작을 흉내 낸 비교 시스템"과 나란히 재생: 격리 등록 지연, 병동 사망, 승인 대기 중 정보 변경+재시작에서 우리만 막음 | 메모 입력 → 약속 생성 → 교대 넘어 추적 → 어긋나면 경보 | 1의 데모 + "왜 늦었나" 설명 화면 + 메모에서 격리 불일치 경보 |
| 새로 만들 것 | 외부 제안 입력 관문(M), 자율화 증빙 묶음(S~M), 비교 시스템과 나쁜 날 재생(M) | 사례 원장·약속 추적(M), 문의 응답 확장(M) | 1 + 지연 설명(S~M) + 격리 불일치 경보(M) |
| 버릴 것 | 정상 날 효율 다듬기, 추정 고도화, 화면 확장 | 관문 고도화 일부 | 정상 날 효율 다듬기 |
| 위험 | 비교 시스템을 일부러 약하게 만들면 가짜 차별점 | 간호사 입력 부담, 메신저 연동 근거 0건, 숫자 근거 적음 | 범위가 커짐: 순서를 엄격히 |
| 경계 | 사후 감시 모드는 설계 항목 GW-13, 운영 중 자동 강등은 EVL-6 → DECISIONS 먼저 | 이동 연쇄는 GW-15 | 같음 |

## 접는 기준 (비평, 방향 1·3 공통)
- K1. 공개 문구 기반 비교 시스템도 나쁜 날 20개에서 위반 0건이면 차별점이 가짜다(비교 대상을 일부러 약하게 고치는 것은 금지).
- K2. 현직자가 장면 셋 중 둘 이상을 "드물다" 또는 "HIS가 이미 막는다"고 답한다.
- K3. 3주 안에 3분 데모가 나오지 않는다.
하나라도 걸리면 "증명 키트로 다시 포장"(최소 피벗)으로 물러난다.

## 하지 않기로 한 것
채널 협상 코디네이터(병동은 통보를 받는 구조라 협상 단계가 없고, 간호사 부담·U8과 충돌), 이동 연쇄 최적화(GW-15), 퇴원 예측 ML, 자체 현황판, 청소·이송 인력 배정(범위 밖).
