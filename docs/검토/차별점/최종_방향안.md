# 차별점 최종 방향안 (2026-11-09)

근거: `방향_비교.md`, `현장문제.md`, `에이전트혁신.md`, `비평.md`, `기존서비스_기능분석.md`(국내 20, 해외 15 서비스), `../AX수요/병원_AX_수요.md`, `../AX수요/엔드픽처_정렬.md`.

## 1. 이미 상품인 것 (차별점이 될 수 없음)
병상 상태판(Epic, Oracle, TeleTracking, GE, 분당서울대), 첫 배정 자동화(아산, 길, 세종, 분당서울대), 퇴원 예측·장벽 관리(Qventus, LeanTaaS, GE, NHS OPTICA), 청소·이송 자동 요청(Epic Rover 등), 음성 기록(서울성모 Voice ENR, Abridge, Dragon Copilot), 운영 계획 what-if(GE 디지털 트윈, 삼성 DOCC), 결정 기록·이행 추적(LeanTaaS 허들, Oracle 전원센터). 국내에서 가장 많이 겹치는 곳은 세종병원(5분마다 자동 배정·HIS 반영, 자동 재배정, 자유 서술 구조화, 예외 담당자 알림).

## 2. 공개 자료에서 아무도 안 하는 것
- G1. 실행 직전 재확인·재검사로 위험한 실행을 막고, **막았다는 것을 재생으로 증명**하는 관문.
- G2. **늦게 온 안전 정보**(격리 결과·오더)를 이미 내려진 배정·연락·청소에 되돌려 반영(보상 단계).
- G3. 사례 하나의 임계 경로와 "그 시점에 알 수 있었나" 판정(집계형 지연 사유는 이미 있음).
- G5. 병원 데이터로 정책·절차 설정을 생성하는 온보딩(모델 학습형 맞춤은 Qventus가 이미 함).
- G7. 남의 AI·RPA 결정 앞에 서는 중립 관문.
- 국내에서는 **퇴원 확정 → 퇴실 → 청소 → 입실** 구간을 다루는 사례가 없다(모두 입원 대기 → 배정 앞단). 빈틈이지만 국내 수요 근거도 없다(설계 가정, 현직자 확인).

## 3. 엔드픽처와의 정렬
- 방향 1(남의 AI 앞 관문)만 하면 사이클을 돌리는 주체가 남이 되어 엔드픽처("사람은 책임 순간에만")에서 벗어난다. 방향 3(묶음)도 대표 장면이 "막았다"라 방어만 보인다.
- 지금 시스템은 L2(제안) 단계다. 감지·실행·보상의 몸은 있으나 예외 판단의 머리가 비어 있다(완전 자동 0%).

## 4. 최종 제안: "책임 순간만 남기는 위임 에이전트 — 관문과 재생 증명 내장"
- **정체성**: 퇴원~입실 사이클을 에이전트가 위임받아 돌리고, 사람은 공식 확정·환자 연락·안전 예외에서만 개입한다. 모든 실행은 관문을 거치고, 에이전트가 혼자 한 일은 다음 날 재생으로 증명한다.
- **에이전트의 머리(새로)**: 병상 선택과 숫자는 결정적 코드(지금대로). 예외가 생기면 **정해진 행동 목록**(다시 요청, 재매칭, 기다림, 누구에게 올림, 보상 실행 등) 중 무엇을 할지 LLM이 판단하고 관문이 검사한다. U8을 넓히는 일이라 사용자 결정과 DECISIONS가 먼저다.
- **대표 장면(데모 순서)**:
  1. D2 늦게 온 격리 양성 결과를 에이전트가 스스로 되돌림(G2): 진행 중인 배정·연락·청소를 보상하고, 같은 병실 접촉자 관리를 감염관리실에 올림.
  2. D1 나쁜 날 재생: 병동 사망, 승인 대기 중 정보 변경과 재시작, 보호자 퇴원일 변경 — 사람 개입이 책임 순간으로만 모임. 세종 공개 기능을 흉내 낸 비교 시스템과 나란히(G1).
  3. D4 매일 밤 증빙 묶음: 그날 에이전트가 혼자 한 일, 관문이 막은 것, 왜 늦었나(G3).
  4. D3 문의에 답한 시각을 약속으로 기록하고 지킴(방향 2의 부품).
  5. D5 같은 하루를 다른 병원 설정(통보형/회신형, 퇴원 순서, 청소 분담)으로 재생 — 2단계 온보딩의 예고(G5).
- **방향 1(중립 관문)**은 나중에 붙일 수 있는 배치 모드로, **방향 3**은 물러날 대체 경로로 둔다.

## 5. 접는 기준
- K1'. 세종 공개 기능 목록을 흉내 낸 비교 시스템도 나쁜 날 20개에서 사람 개입 분포·위반이 같으면 차별점이 가짜다(비교 대상을 일부러 약하게 만들지 않는다).
- K2'. 현직자가 늦은 격리 결과와 퇴원~입실 조율을 "드물다" 또는 "HIS가 이미 한다"고 답한다.
- K3. 3주 안에 3분 데모가 나오지 않는다.
하나라도 걸리면 "증명 키트로 다시 포장"(최소 피벗)으로 물러난다.
