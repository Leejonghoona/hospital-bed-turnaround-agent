# 지침과 현장 운영의 차이: 공개 자료 시범 조사

조사일: 2026-11-08. 방법: WebSearch, curl로 원문 확인(원문은 `research/field/` 아래에 저장). koreascience.kr은 연결이 끊겨 대부분 열리지 않았다. koreascience.or.kr, synapse.koreamed.org, PMC, 언론사 페이지는 열렸다. 원문을 열지 못하고 검색 요약만 본 항목은 [미대조]로 표시했다.

## 1. 결론: 부분 가능

- **알 수 있는 것**: (a) 지침이 병원 재량을 얼마나 허용하는지, (b) 병원 유형별 이행 수준(설문 비율), (c) 자원 부족의 크기(1인실 수, 격리 공간 부족 응답률), (d) 지연이 생긴다는 간접 신호.
- **알 수 없는 것**: 특정 병원이 공기주의 병실 퇴실 후 실제로 몇 분을 기다리는지, 퇴실 청소에 몇 분이 걸리는지, 병실별 실측 환기횟수. 이런 수치를 담은 국내 공개 자료는 찾지 못했다.
- **이유**:
  1. 지침 원문이 처음부터 병원별 조정을 허용한다. "시간당 공기교환 횟수 4회 기준 2시간 정도 **또는 기관의 공조시스템에 따라 조정**"이라고 적혀 있다. 그래서 병원마다 값이 다른 것은 위반이 아니라 지침이 허용한 범위다. 그런데 병원이 실제로 정한 값은 내부 규정이라 공개되지 않는다.
  2. 국내 실태조사는 대부분 감염관리 담당자의 자가보고 설문이다. 문항도 "규정이 있는가, 시행하는가"를 묻고 시간이나 횟수는 묻지 않는다.
  3. 환기 실측 연구는 시설 설계와 성능 평가가 목적이라 몇 곳만 다루고, 운영상의 대기 시간은 다루지 않는다.

## 4. 공개 자료로 알 수 없는 것과 알아내는 방법

| 알 수 없는 것 | 알아내는 방법 |
|---|---|
| 병원별 공기주의 퇴실 후 실제 대기 시간과 그 결정 근거(ACH 실측값 기반인지, 관행인지) | 감염관리간호사(CNIC) 반구조화 인터뷰 5~10명. 대한감염관리간호사회를 통한 짧은 설문으로 "대기 시간, 근거, 단축 사유" 3문항 |
| 퇴실 청소 소요시간의 분포, 종말소독과 일반 청소의 차이 | 환경관리팀 인터뷰, 직접 관찰(time-motion). 병원 데이터가 있다면 EMR이나 병상관리 시스템의 "퇴원 처리 시각 → 병상 '청소 완료' 상태 변경 시각" 간격에서 추정 |
| 운영 중 병실의 실측 환기횟수 | 시설팀 TAB(풍량 측정) 보고서 요청. 공개되지 않으므로 협조가 필요하다 |
| 격리 대상인데 1인실을 못 받아 다인실·커튼으로 간 비율 | 병원 데이터: 격리 지시 시각, 병상 배정 이력, 병실 유형을 결합. 또는 감염관리실 월간 지표(격리 이행률) 요청 |
| 지침값과 현장값의 의도적 차이(예: 2시간을 1시간으로 단축) | 인터뷰에서 "기관 공조시스템에 따라 조정" 조항을 실제로 쓰는지 직접 질문. 병원 내부 규정집 열람 협조 |

**프로젝트 적용 시사점 [추정]**: 데모의 합성 데이터에서는 공기주의 환기 대기를 고정값(120분)으로 두지 말고 병원 정책 파일(YAML)의 매개변수로 두는 것이 좋다. 지침이 기관별 조정을 허용하기 때문이다. 기본값은 지침값으로 하고, "기관 조정값"은 출처를 [가정]으로 표시한다. 격리실이 부족할 때 쓰는 단계(1인실 → 코호트 → 커튼 차단)는 업무지침서 문구(#6)를 근거로 모델링할 수 있다.
