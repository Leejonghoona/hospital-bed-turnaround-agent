- 산출물: `docs/검토/현직자_설문_문구.json`(구글 설문지 생성용). 원본 HTML과 `현직자_질문지_검수.md`는 고치지 않았다.
- 지킨 것: 각 문항이 확인하려는 가정(`현직자_질문지_검수.md` 5절 매핑표)은 그대로 두었다. 문항 번호(0, 1~11, S1~S10)와 필수/선택 구분도 그대로다. 하위 문항은 구글 설문지에서 각각 별도 질문이 되므로 "1-1", "S4-2"처럼 번호를 붙이고 제목만 읽어도 뜻이 통하게 썼다.

## 1. 전체 원칙

1. **제목은 질문 한 문장.** "답해 주시는 분", "같은 병실 배치", "아시면만", "실제로 쓰는 표현 2~3개"처럼 명사구로 끝나던 제목을 모두 "~나요?", "~주시겠어요?"로 바꿨다.
2. **"~요"체로 통일.** 제목과 설명은 해요체. 선택지는 짧은 명사구(예: "퇴원약 대기")를 기본으로 하고, 문장이 필요한 선택지는 문항 안에서 모두 "~요"로 맞췄다("있다/없다", "뜬다", "안 둔다" 같은 해라체 선택지를 없앴다).
3. **한 문항에 하나만.** 하위 문항이 있던 문항(0, 1, 4, 10, 11, S4, S5, S7, S10)은 각각 따로 묻는다. 특정 선택지에만 붙던 입력칸(6번, S7 성별)은 구글 설문지가 지원하지 않으므로 짧은 주관식 하위 문항으로 나눴다.
4. **선택지는 겹치지 않고 빠짐없이.** 구간 경계를 "미만/이상"으로 바로잡고, "둘 다"처럼 다른 선택지와 겹치는 항목은 체크박스로 바꿔 없앴다. 빠진 경우(퇴원 이틀 전 이상, 병동 근무가 아닌 응답자 등)를 채웠다.
5. **"모름"은 맨 끝.** 구글 설문지의 '기타'(직접 입력)는 항상 목록 맨 아래에 붙으므로, "모름"은 일반 선택지 중 맨 끝, 즉 '기타' 바로 위가 된다. 원본의 "기타", "목록에 없음" 선택지는 `other: true`로 바꿨다.
6. **현장 용어 그대로, 번역투·개발자 말투 없애기.** "원무"→"원무과", "단톡"→"메신저(단톡방 포함)", "전산"(쪽지·요청 화면), "퇴원 처리(수납)", "인계". "~하는 것은 ~인 때" 같은 번역투, "말하기 곤란" 같은 딱딱한 표현을 고쳤다.
7. **직무 표시.** 구글 설문지에는 꼬리표가 없으므로 [간호] [원무] [공통]을 설명(help) 맨 앞에 둔다.
8. **필수도 구글 설문지 '필수'는 끔.** 모르는 문항 때문에 막히지 않게 하고, 대신 안내문과 필수 섹션 설명에서 "비워 두기보다 '모름'"을 권한다.

## 4. 바꾸지 않은 것

- 각 문항의 확인 의도와 매핑(5절)은 그대로다. 6번을 6-1/6-2로 나눈 것도 B2(실제로 얼마나 비워 두나)를 받기 위해서다.
- 문항 번호와 필수/선택 구분은 그대로다(0, 1~11, S1~S10). 구글 설문지 항목 수는 하위 문항 분리로 늘었다: 답하시는 분 4, 필수 17(0-5 포함), 선택 17.
- 9번의 예시 목록은 고르기 칸으로 두었다(설계 문서 2.2의 결정). 체크박스에서 "늦게 나간 퇴원이 없었음", "모름"과 다른 선택지를 함께 고르는 것은 구글 설문지에서 막을 수 없으니, 받은 뒤 해석할 때 걸러 낸다.

## 5. 구글 설문지로 옮길 때

- `type`: one = 객관식, many = 체크박스, line = 단답, text = 장문. `other: true`면 '기타' 옵션을 켠다.
- `required`는 모두 false다. 섹션은 구글 설문지의 '섹션'으로 세 개를 만든다.
- 6-2, S7-3은 앞 문항의 특정 답에만 해당한다. 섹션 이동 분기를 쓰지 않고 설명에 "~고르신 경우에만"이라고 적었다(문항 하나 때문에 섹션을 쪼개면 흐름이 끊긴다).
