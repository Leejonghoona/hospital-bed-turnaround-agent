# 병동 사망과 급변 전동 조사 (2026-11-09)

목적: 병상이 퇴원이 아닌 이유로 비는 두 경로(병동 내 사망, 중증 악화로 인한 중환자실 급변 전동)를 설계하기 전에 현장 절차를 확인한다(CLAUDE.md 7번). 모두 검색 요약으로 판단했다.

## 병동 내 사망
- 국내 성인 환자 사후 간호 프로토콜(2023): 사망 확인·통보 → 시신 간호 → **환자 확인(가족 면회)** → 이송 → 기록의 5단계, 일반 권고 3개·세부 권고 43개. 두 병원 전문가 6명과 간호사 30명이 타당도 평가. ([koreascience](https://koreascience.kr/article/JAKO202317154013350.page?lang=ko))
- 해외 지침도 사후 처치(라인·튜브 제거, 식별표) 뒤 영안 구역으로 이송한다고 적는다.
- **설계 반영**: 사망 확인 시점이 아니라 **안치실 이송 시점에 병상이 빈다.** 면회·사후 처치 동안은 병상을 사용 중으로 본다. 이송까지 걸리는 시간 기준은 찾지 못했다(병원 내부 규정, 설계 가정 없이 이벤트로만 받는다).

## 중환자실 급변 전동
- 병원 안내는 전동 시 원무팀이 병실을 배정하고 병실 정리가 끝나면 이동한다고 적는다(삼성서울병원 중환자실 입·퇴실 안내). 중환자실 → 병동 방향의 절차다. ([삼성서울병원](http://www.samsunghospital.com/home/info/ICUinto.do))
- **원래 병동 병상을 잡아 두는(hold) 공개 규정은 찾지 못했다.** 영어권 "bed hold"는 요양시설 거주자가 병원에 갈 때의 규정이다. 호주 NSW의 중환자 병상 관리 절차는 중환자실에서 병동으로 돌아갈 병상 배정 지연을 다룰 뿐이다. ([SESLHD PR 228](https://www.seslhd.health.nsw.gov.au/sites/default/files/documents/SESLHDPR%20228%20Critical%20Care%20Bed%20Management%20Procedure_1.pdf))
- **설계 반영**: 급변 전동 시 원래 병상은 **기본으로 바로 빈다**. 병원이 잡아 두는 경우를 위해 `hold` 표시를 두고, 잡아 둔 동안은 배정 후보·확정·직접 수정에서 모두 막는다. 그 병상에 걸린 사전 매칭은 풀고 다시 찾는다(연락 후면 담당 검토와 재연락). 기본값(안 잡음)과 잡아 두는 기간은 설계 가정이며 현직자 확인 대상이다.
