# 현장 조사·조사 범위 종합과 결정안 (2026-11-09)

근거 파일: `docs/검토/현장조사/`(사용자제공_원문, 원무_병상배정_실무, 병동간호_실무, 감염관리_청소_실무, 유튜브_요약_A·B, EMR_병상관리, 국내EMR_시스템, 종합), `docs/검토/조사범위/`(방법론, 현장전문가, 제품전략). 작업자가 원문을 직접 연 핵심 출처: 아산 입원 절차, 서울고법 2013누25193, 서울성모 입원원무팀 조직, QIH 2022(격리 등록률 53%), 해운대백 과업지시서(13:30 침상 정리), 결핵 진료지침 5판 384쪽, 표준예방지침 5.4.5.1, 남녀 병실 유지 보도(헤럴드경제 2026-05-31).

## 1. 한눈 요약
1. 문제(퇴원부터 입실까지 부서가 따로 돌고 어긋나면 전화로 다시 짠다)는 여전히 맞다. 서울아산은 배정 담당이 목록을 "일일이" 보고 50여 개 기준을 적용하며 요청이 하루 약 250건이다(원문).
2. 그러나 **하루 장면이 현장과 다르다.** 공개 안내 14곳 모두 배정은 입원 당일 오전, 병동은 "통보"를 받고 준비되면 "올려주세요"라고 한다. 우리 설계의 "전날 17:40 사전 매칭"과 "병동 회신이 있어야 확정"은 현장 근거가 없다.
3. 퇴원은 "11시까지 퇴실", 순서는 심사 → 수납 → 영수증 제시 → 퇴원약 전달. 입실은 14~17시. 우리 합성 데이터는 퇴실 중앙값 13:06, 입원 예정 10~15시로 현장보다 늦거나 이르다.
4. 병상 "준비 완료"를 전산에 누가 입력하는지는 국내 근거가 4번의 조사에서 0건이다. 중소병원 매뉴얼은 퇴원 뒤 청소를 간호 업무로만 적는다. 해외(Epic, MEDITECH, NHS)는 근거가 많다.
5. **법령 문제 1건**: 남녀 병실 구별은 의료법 시행규칙상 의무이고(보도 원문, 조문 원문 대조 남음), 예외는 중환자실과 가족 2인실뿐이다. 우리 정책은 "사유 입력 후 진행"이라 낮다.
6. 차별점 재정의: 상태판·청소 앱·퇴원 예측·배정 추천은 이미 있다(Epic, 분당서울대, 길병원 자동 배정, 이지케어텍 Medical OS). 남는 차별점은 한국 원무 절차를 아는 사례 추적, 실행 게이트웨이와 재생 평가, 비정규 경로 안전, 2단계 온보딩.

## 3. 기능 확장안
기본값은 지금대로 두고(승인된 회귀 시나리오 30개 보호) **병원 프로필 설정**으로 더한다.

### 3.1 1단계 안에서 바로잡을 것 (근거 있음)
| 항목 | 지금 | 바꾸는 안 | 크기 |
|---|---|---|---|
| A. 남녀 병실 | 사유 입력 후 진행 | 법령 금지 등급, 예외는 중환자실·가족 2인실 | S (조문 대조 뒤) |
| B. 배정 시점 | 전날 사전 매칭 | "당일 오전 배정 모드" 추가, 전날 매칭은 "가배정 초안(설계 가정)" | M |
| C. 병동 확인 | 회신이 확정 조건 | 병원 설정: 통보형(기본 후보) / 회신형 / 이의 기간 | S |
| D. 퇴원 단계 순서 | 퇴원약 준비 → 수납 | 병원 설정, 현장형은 심사·조제 동시 → 수납 → 약 전달 | M |
| E. 보호자 지연 | 당일 몇 시간 지연만 | 당일 지연 / 퇴원일 변경 두 갈래, 퇴원 라운지(병상 먼저 비움) | M |
| F. 1인실 희망 | "1인실 희망" 검토 사유 | "희망 등급과 다른 배정"으로 넓힘 | S |
| G. 격리 정보 | 오더 값 그대로 | 등록 누락 가능성(53%) 반영, "아직 모름" 상태 | S |
| H. 생성기 분포 | 퇴실 13:06, 입원 10~15시 | 퇴실·입실 시간대를 현장 규정에 맞춤(또는 "개선 전 병원" 근거를 DECISIONS에) | M |

### 3.2 1단계 확장 후보
청소 2단계(미화 + 병동 보조 13:30 일괄 정리)와 청소 인력 시간대 공백, 가퇴원(야간·휴일), 선별검사 결과 타이머, 병동 운영 병상 상한, HIS "빈 침대"와 우리 "입실 가능"을 나누는 관측 이벤트, 이동 연쇄 "표시만".

### 3.3 하지 않음 / 2단계 이후
이동 연쇄 최적화(설계 항목 GW-15), 퇴원 예측 ML, 자체 현황판, 청소·이송 인력 배정(범위 밖), 수술 연동, 응급실 대기 전체 판단. 2단계 온보딩 입력값 17개 목록은 확정해 둔다(제품전략 5절).
