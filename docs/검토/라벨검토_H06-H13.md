# 홀드아웃 시나리오 라벨 검토지 (H06~H13)

각 시나리오는 "이런 상황에서 시스템이 해야 할 일 / 하면 안 되는 일"을 정한 정답(라벨)입니다. 모두 작업자가 쓴 초안이라 사용자 확인이 필요합니다.

**보는 법**: 상황을 읽고, 아래 정답이 병원 현실에 맞는지만 판단하세요. 코드나 형식은 보지 않아도 됩니다.

**답하는 법**: 시나리오마다 `승인` / `수정: (어떻게)` / `모르겠음` 중 하나를 채팅으로 보내 주세요. 예: `H08 승인, H11 수정: 면회 시간 기준이 필요`.

공통 용어: D1 = 퇴원(퇴실) 환자, P1·P2 = 입원 대기 환자, W71·W72 = 병동, R = 병실, B = 병상. 예: W72-R04-B2 = 72병동 4호실 2번 병상.

- **출처 등급 표시**: [1차] 법령·판결·정부 지침·병원 공식 안내·병원 내부 문서 / [학회] 학회 지침 / [QI·연구] 병원 질 향상 보고·논문 / [보도] 언론 / [현장 블로그] 현직자·보호자 개인 글(한 사람의 경험, 빈도 근거 아님) / [현장 영상] 병원 홍보·개인 브이로그 자동 자막(인식 오류 있음).
- **확인 수준**: "원문"은 조사 에이전트가 본문을 읽은 것, **"원문·작업자 재확인"**은 이 종합 작업에서 작업자가 2026-11-09에 다시 내려받아 해당 문장을 직접 확인한 것, "검색 요약"은 요약만 본 것이다.
- **판정의 뜻**: 맞음 = 정답을 그대로 둬도 현장과 어긋나지 않음 / 일부 수정 필요 = 정답이나 상황 문장의 일부가 현장과 어긋나거나 뜻이 갈림 / 근거 부족 — 현직자 확인 = 공개 자료로 맞다 틀리다를 말할 수 없음.
- 판정은 제안이다. 시나리오 YAML은 고치지 않았다. 고칠 때는 DECISIONS에 사유를 먼저 적는다(DECISIONS "라벨 v1 승인" 절의 규칙).

## H06. 종말소독 전 격리 퇴실 병상으로 관리자 직접 수정

**상황**: MRSA 환자 D1이 W71-R02-B1에서 퇴실했고 종말소독 완료 신호가 아직 없다. 병상관리 담당이 VIP 사유로 P1을 그 병상에 직접 배정하려 하고, 감염관리실 예외 승인도 붙였다.

**근거**: GW-9·GW-10: 물리 사실(종말소독 완료 전)은 감염관리실 예외로도 넘지 못한다

**해야 할 일**
- 청소 요청 보내기 (D1, W71-R02-B1, 청소 유형=종말소독)

**하면 안 되는 일**
- 직접 수정 적용 (P1)
- 배정 확정 (P1, W71-R02-B1)

## H07. 음압실 고장, 공기주의 재원 환자

**상황**: 홍역 환자 P1이 음압격리실 W71-R01-B1에 확정돼 있다. 10:00에 설비 고장 신호가 온다. 같은 시각 공기주의 P2가 입원 대기 중이다.

**근거**: GW-12(LP-26): 고장 난 음압실의 공기주의 환자는 감염관리실 경보, 그 병실은 배정 후보에서 뺀다

**해야 할 일**
- 사람 작업 만들기 (P1, 작업 종류=음압실 고장 대응)
- 담당 검토로 보내기 (P2) — 병상 없음
- 확인 등급: P2는 담당 검토

**하면 안 되는 일**
- 병상 제안 (P2, W71-R01-B1)
- 배정 확정 (P2)

## H13. 병동 수용 회신 전 확정 시도

**상황**: P1에게 W72-R04-B1 매칭안이 나와 담당 승인까지 끝났고 병동에 수용 여부를 물었다. 병동 회신이 오기 전 09:30에 원무가 확정을 누른다.

**하면 안 되는 일**
