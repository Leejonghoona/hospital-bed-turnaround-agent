# 홀드아웃 시나리오 라벨 검토지 (H06~H13)

각 시나리오는 "이런 상황에서 시스템이 해야 할 일 / 하면 안 되는 일"을 정한 정답(라벨)입니다. 모두 작업자가 쓴 초안이라 사용자 확인이 필요합니다.

**보는 법**: 상황을 읽고, 아래 정답이 병원 현실에 맞는지만 판단하세요. 코드나 형식은 보지 않아도 됩니다.

**답하는 법**: 시나리오마다 `승인` / `수정: (어떻게)` / `모르겠음` 중 하나를 채팅으로 보내 주세요. 예: `H08 승인, H11 수정: 면회 시간 기준이 필요`.

공통 용어: D1 = 퇴원(퇴실) 환자, P1·P2 = 입원 대기 환자, W71·W72 = 병동, R = 병실, B = 병상. 예: W72-R04-B2 = 72병동 4호실 2번 병상.

## H06. 종말소독 전 격리 퇴실 병상으로 관리자 직접 수정

**상황**: MRSA 환자 D1이 W71-R02-B1에서 퇴실했고 종말소독 완료 신호가 아직 없다. 병상관리 담당이 VIP 사유로 P1을 그 병상에 직접 배정하려 하고, 감염관리실 예외 승인도 붙였다.

**근거**: GW-9·GW-10: 물리 사실(종말소독 완료 전)은 감염관리실 예외로도 넘지 못한다

- 청소 요청 보내기 (D1, W71-R02-B1, 청소 유형=종말소독)

**하면 안 되는 일**
- 직접 수정 적용 (P1)
- 배정 확정 (P1, W71-R02-B1)

## H10. 처방 수정으로 늦어진 퇴원약

**상황**: D1의 퇴원처방이 09:00에 발행됐고 10:00에 수정(퇴원 보류)됐다. 퇴원약은 11:40에 병동에 왔다.

**근거**: DAT-7·SAG-6(LP-27): 지연 타이머는 처방 발행 기준, 처방 수정은 지연 사유로 기록

## H12. 급변 전동, 원래 병상 잡아 두기

- 퇴원 등록 확인 요청 (D1)
