# 담당자별 현실 괴리 조사 요약 (2026-11-10)

담당자 5명분의 조사 에이전트가 우리 코드와 1차 출처를 짝지어 괴리를 찾았다. 핵심 출처는 다시 직접 확인했다. 확인한 출처: 세브란스 입원 안내, 요양급여기준 별표 2, 복지부 2026-05-31 보도설명, 서울아산 소식지, 일산병원 연보, Cerner 교육 자료, 질병관리청 2026 관리지침 인용. 상세는 01~05 파일에 있다.

## 반영함 (PoC 중)

| 담당 | 괴리 | 반영 |
|---|---|---|
| 관리자·보안 | 잠긴 계정이 맞는 비밀번호와 데모 로그인으로 열림 | 잠금 유지, 관리자 해제 |
| 관리자·보안 | 서버에 미사용 자동 차단이 없음 | 서버 15분 잠금, 본인 비밀번호로 해제 |
| 관리자·보안 | 접속기록이 메모리에만 있고 항목이 모자람 | SQLite 추가 전용, 해시 연결, 서버 시각, 접속지, 로그인 실패, 잠김 |
| 관리자·보안 | 병동 계정이 다른 병동으로 바꿔 열람 | 소속 병동 고정 |
| 관리자·보안 | 관리자가 환자 정보와 원무 처리 권한을 가짐 | 접속기록과 계정만 맡음 |
| 원무 | 입원 안내 연락에 마감이 없음 | 당일 12:00 마감(세브란스 08:30~11:00, 분당서울대 11:30) |
| 원무 | 수속 시각이 창구 마감 뒤로 나감 | 09:00~17:30만 고름 |
| 원무 | 연락 결과에 연기·취소가 없음 | 입원 연기, 입원 취소 기록 뒤 병상 해제 |
| 원무 | '차액' 문구가 틀림, 격리 1인실에도 동의 작업 | '입원실 이용 비용 전액' 문구, 격리 1인실은 동의 작업 제외 |
| 병동 | 병동 이의가 곧바로 배정 해제(병동 거부권) | 병동 화면은 원무에 의견을 보내고, 원무가 정함 |
| 감염관리 | 1인실이 없을 때 제자리 격리 선택이 없음 | 감염관리실 결정 사유에 '지금 병상 유지(제자리 격리)' |

|---|---|---|

| 퇴원 단계 | 정규 퇴원 비율 36.5%(근거 62.7%), 정규 퇴원 심사·수납이 9시 전에 끝남 | 생성기 수정과 재측정 |
| 퇴원 단계 | 수납 지연 긴 꼬리 없음, 주말을 평일처럼 처리 | 생성기 수정과 재측정 |
| 감염관리 | 접촉주의 균은 모두 1인실 요구(병원 설정이어야 함), 비코호트 다인실 동실자 취약성 미검사, 다중 병원체 미표현 | 온톨로지·생성기 변경, 안전 회귀 다시 확인 필요 |

| 원무 | 차액 동의를 연락 때 받기, 희망 병실 등급(2인실) 세분, 병상 없음 일정 조정은 진료과 연락 | 흐름 변경 |
| 관리자·보안 | 권한 부여·변경 이력 3년 보관, 비밀번호 개별화, 외부 접속 추가 인증 | 데모 한계로 기록 |
