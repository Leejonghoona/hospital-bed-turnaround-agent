검토일 2026-11-10. 저장소는 고치지 않았다.
측정 방법: 생성기를 `GeneratorConfig.realistic()`로 시드 0~199번까지 돌렸다(퇴원 6,000건, 정상 퇴원 5,400건). 스크립트는 scratchpad/probe.py에 있다.
원문 확인 방법: curl과 pdftotext로 직접 내려받아 읽었다. 내려받은 파일은 scratchpad/dl4/에 있다.
아래 내용은 이미 정리된 지적과 겹치지 않게 골랐다. 이미 정리된 지적의 출처는 DECISIONS 2026-11-09·10, 업무현실검증, 스펙현실검증, 제안요청서_QI_통계, 1단계·2단계 단계검수다.

## 3. 확인 안 됨(간극으로 세지 않음)

- 국내 퇴원 병실의 일반 청소·종말소독 소요시간(분): 이번 검색에서도 국내 실측을 찾지 못했다. 지금 값(일반 35/55, 종말 75/110, 다인실 침상 단위 20/35, `distributions.py:17-18,31`)은 설계 가정으로 유지한다. 실측(시드 200): 퇴실 → 청소 시작 중앙 56분, 퇴실 → 입실 가능 중앙 125분, P90 208분.
- 청소·침상 준비가 끝났다는 신호를 국내에서 누가 어떤 화면으로 원무에 알리는지: 공개 원문을 찾지 못했다.
- 주말 퇴원량 감소 폭: 기사(2005)의 방향만 있고 정량 자료는 없다.
- 울산대 CRE 종결소독 학위논문(oak.ulsan.ac.kr 12744): PDF가 빈 파일로 내려와 읽지 못했다.

## 4. 기존 지적 재확인(새 간극 아님, 아직 코드에 반영되지 않음)

- 1단계 M-2(보호자가 오기 전에 수납·교육이 끝남): 지금 실측에서 보호자 도착 전 수납 77.0%, 퇴원약 전달 54.4%다. 검수 당시(53%, 40%)보다 커졌다. G3을 고치면 함께 줄어든다.
- 2단계 M3(심사 운영 시간·가퇴원), 2단계 3절(제증명 서류 대기, 전원 이송 차량 지연)은 그대로 남아 있다.
