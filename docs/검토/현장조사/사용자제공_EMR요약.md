# 사용자가 준 병상 준비 확인 방식 요약 (2026-11-09, 검증 전)

사용자가 검색해 붙여 준 글이다. 문체로 보아 검색 엔진의 AI 요약일 가능성이 있어, **각 주장은 원문 근거를 찾기 전까지 "검증 전"**으로 둔다. 근거 영상: https://www.youtube.com/watch?v=z93nOCRuCdQ , https://www.youtube.com/watch?v=ol6Cxlm6WZE (자막은 사용자 노트북에서 받는다).

주장 목록 (검증 결과는 `EMR_병상관리.md`에 적는다):
1. EMR·병상 관리 프로그램 현황판에 병상 상태(공실, 입실 예정, 청소 중, 준비 완료 등)가 실시간 표시된다.
2. 퇴원·전실 시 병동 간호사가 EMR에서 퇴실 처리(재원 종료)를 입력한다.
3. 미화원이나 병동 인력이 청소·시트 교체 뒤 전산에 "청소 완료/입실 준비 완료"를 입력한다.
4. 전산 반영이 늦으면 원무·응급실·외래가 병동에 전화해 준비 여부를 확인한다. 원무과 병상 관리자가 전체를 총괄한다.
5. 늦으면 병동 인력이 직접 병실을 돌며 물품(산소 유량계 등)을 점검한다.
6. 상태 색상 구분: 퇴원 예고, 퇴실·청소 대기, 준비 완료, 입실 배정됨.
7. 상태가 바뀌면 간호사 PC 팝업·알림음, 원내 메신저 자동 메시지가 간다.
8. 스마트 병원은 미화 인력이 업무용 스마트폰(PDA) 앱에서 "청소 완료"를 누르면 현황판이 바뀐다.
9. 모바일 기기가 없는 병원은 병실 전화기로 내선·코드(예: *123#)를 눌러 상태를 바꾼다.
10. 청소 완료가 떠도 담당 간호사가 격리 해제, 산소·흡인기, 낙상 방지 세팅을 확인한 뒤 "수용 가능"을 클릭해야 이송이 시작된다.
