description: 구독 경유 Claude 측정을 돌리고 결과를 저장·커밋·푸시한다
---
구독 계정 Claude로 모델 성능점검(인젝션·질의·계획)을 돌린다. 개인 평가 용도이고 합성 데이터만 쓴다.

1. 저장소 루트에서 `python -m pip install -q -e ".[claudesub]"`를 실행한다.
2. `python scripts/run_claudesub.py --dry-run`으로 5문항 시험을 돌린다. 실패하면 오류를 사용자에게 쉬운 말로 알리고 멈춘다(로그인 안 됨이면 `claude`를 실행해 로그인하라고 안내).
3. 시험이 되면 `python scripts/run_claudesub.py`를 돌린다. 오래 걸리면 백그라운드로 돌리고 끝날 때까지 기다린다.
4. 스크립트가 결과 파일을 커밋·푸시한다. 끝나면 모델마다 인젝션 공격 성공률, 질의 정답률, 계획 1순위 일치율을 표로 요약하고, 한도로 멈춘 모델이 있으면 "나중에 /claude-measure를 다시 실행하면 이어서 잰다"고 알린다.

하지 말 것: ANTHROPIC_API_KEY를 설정하거나 쓰지 않는다(API 과금). 결과 파일을 고치지 않는다. 다른 파일을 커밋하지 않는다.
